    Задача 1: Codewars: "Two Sum" (Based on Leetcode)

    Write a function that takes an array of numbers (integers for the tests) and a target number. It should find two different items in the array that, when added together, give the target value. The indexes of these items should then be returned in a tuple / list (depending on your language) like so: (index1, index2).

    For the purposes of this kata, some tests may have multiple answers; any valid solutions will be accepted.

    The input will always be valid (numbers will be an array of length 2 or greater, and all of the items will be numbers; target will always be the sum of two different items from that array).

    Примечание: Хотя в задаче просят "tuple", в C++ для пары значений лучше всего подходит std::pair.

    На русском:

    Напишите функцию, которая принимает массив чисел (целых чисел для тестов) и целевое число (target). Она должна найти в массиве два разных элемента, которые при сложении дают целевое значение. Индексы этих элементов должны быть возвращены в виде пары (tuple/list) вот так: (index1, index2).

    В рамках этого ката некоторые тесты могут иметь несколько вариантов ответа; любой правильный ответ будет принят.

    Входные данные всегда корректны: массив длиной 2 или более, все элементы — числа; target всегда является суммой двух разных элементов из этого массива.

    Примеры данных:

two_sum({1, 2, 3}, 4); // returns {0, 2} or {2, 0}
two_sum({3, 2, 4}, 6); // returns {1, 2} or {2, 1}
    Решение: 
    #include <vector>

std::pair<std::size_t, std::size_t> two_sum(const std::vector<int>& numbers, int target) {
    for (std::size_t i = 0; i < numbers.size(); ++i) {
        for (std::size_t j = i + 1; j < numbers.size(); ++j) {
            if (numbers[i] + numbers[j] == target) {
                return {i, j};
            }
        }
    }
    return {0, 0};
}
    На заметку:

    #include <vector> — это подключение стандартной библиотеки для работы с динамическими массивами (векторами).
    Зачем: Без этой строки компилятор не поймет, что такое std::vector, и выдаст ошибку.
    Почему на Codewars его нет: На Codewars этот заголовок (и другие базовые) часто уже скрыто подключен за кулисами в тестовой среде для удобства, чтобы ты писал только саму функцию. В реальном проекте в VS Code его обязательно нужно писать самому в начале файла.


    Инсайт дня: Индексы vs Размер (Off-by-one error)

    Индекс (Index) — это смещение (дистанция) от начала. От первого элемента до него самого — 0 шагов. Поэтому первый элемент имеет индекс 0.
    Размер (Size) — это общее количество штук. Если в массиве есть хотя бы один предмет, его размер — 1.
    В векторе размером N последний доступный индекс всегда равен N - 1.

    Пример:
    Если numbers.size() == 5, то:
    Элементы: 1-й, 2-й, 3-й, 4-й, 5-й.
    Индексы: 0, 1, 2, 3, 4.
    Попытка обратиться к numbers[5] приведет к ошибке, так как индекса 5 не существует.

    Вывод: Всегда помнить, что цикл должен идти до i < size, а не i <= size.

    Задача 2: Codewars: "Even or Odd"

    Create a function that takes an integer as an argument and returns "Even" for even numbers or "Odd" for odd numbers.

    На русском:

    Создайте функцию, которая принимает целое число в качестве аргумента и возвращает "Even" (Четное) для четных чисел или "Odd" (Нечетное) для нечетных.

    Примеры данных:

even_or_odd(2);    // returns "Even"
even_or_odd(7);    // returns "Odd"
even_or_odd(-42);  // returns "Even"
    Решение: 
    #include <string>

std::string even_or_odd(int number) 
{
  if (number % 2 == 0) {
    return "Even";
  } else {
    return "Odd";
  }
}
    На заметку:

    std::string — это тип возвращаемого значения функции, так как мы возвращаем слова, а не числа.
    Синтаксис if/else: условие всегда пишется в круглых скобках (), а блоки кода — в фигурных {}. Каждая команда внутри заканчивается точкой с запятой ;.


    Инсайт дня: Оператор остатка от деления (%)

    Оператор % (modulo) возвращает то, что осталось после деления одного целого числа на другое.
    Если число % 2 == 0, значит оно делится на два нацело — это главный способ определить четность в программировании.

    Пример:
    Если number == 7, то 7 % 2 даст 1. Результат не 0, значит число нечетное.
    Если number == 8, то 8 % 2 даст 0. Результат 0, значит число четное.

    Вывод: Любая задача, где нужно проверить кратность одного числа другому, решается через оператор %.

    Нам нужна функция, которая может преобразовать число (целое число) в строку. Какие способы решения этой задачи вы знаете?

    ```cpp

    Примеры данных:

    123  --> "123"
999  --> "999"
-100 --> "-100"
```
    Решение: 
    #include <string>

std::string number_to_string(int num) {
  return std::to_string(num);
}
    На заметку:

    #include <string> — необходимо подключить, чтобы использовать функцию std::to_string().
    std::to_string() — принимает числовые типы (int, float, double) и возвращает их строковое представление (std::string). Это самый простой и современный способ конвертации в C++.


    Инсайт дня: Строка vs Число (Типизация)

    Число (int) — это значение, с которым можно проводить математические операции (сложение, умножение).
    Строка (string) — это набор символов (текст). Даже если в строке написано "123", компьютер воспринимает это как последовательность символов, а не как число.

    Пример:
    Если num = 123, то 123 + 1 даст результат 124.
    Если мы работаем со строкой "123", то попытка прибавить к ней "1" приведет к склейке текста — "1231".

    Вывод: Всегда следи за типами данных: для расчетов используй int, для вывода текста или хранения строковых ID — string.

    Задача 4: Codewars: "Guess the Number Game"

    Imagine you are creating a game where the user has to guess the correct number. But there is a limit of how many guesses the user can do.

    If the user tries to guess more than the limit, the function should throw an error. If the user guess is right it should return true. If the user guess is wrong it should return false and lose a life. Can you finish the game so all the rules are met?

    На русском:

    Представьте, что вы создаете игру, в которой пользователь должен угадать правильное число. Но количество попыток (догадок), которые может сделать пользователь, ограничено. Если пользователь пытается угадать больше раз, чем позволяет лимит, функция должна выбросить ошибку. Если догадка пользователя верна, функция должна вернуть true. Если догадка неверна, функция должна вернуть false и пользователь теряет одну жизнь. Можете ли вы дописать игру так, чтобы соблюдались все эти правила?

    // Пример использования:
Guesser game(10, 2); 
game.guess(10); // возвращает true
game.guess(1);  // возвращает false, осталась 1 жизнь
game.guess(1);  // возвращает false, жизней 0
game.guess(1);  // выбрасывает std::runtime_error
    Решение: 
    #include <stdexcept>

class Guesser
{
public:
    // Конструктор инициализирует начальные значения через список инициализации
    Guesser(int number, int lives)
      : number(number), lives(lives)
    { }

    bool guess(int n)
    {
        // 1. Проверяем наличие жизней ПЕРЕД ходом. 
        // Если их 0 или меньше — бросаем ошибку.
        if (lives <= 0) {
            throw std::runtime_error("Expect error: already dead");
        }

        // 2. Проверяем, угадано ли число (сравниваем n и number)
        if (n == number) {
            return true;
        }

        // 3. Если не угадал — уменьшаем жизни и возвращаем false
        // Сюда код дойдет, только если условия выше не сработали.
        lives--;
        return false;
    }

private:
    int number, lives; // Память объекта (приватные переменные)
};
    На заметку:

    #include <stdexcept> — библиотека для работы со стандартными исключениями (ошибками).
    throw std::runtime_error("текст") — команда, которая мгновенно прерывает работу функции и сообщает о критической ошибке.
    lives-- — декремент. Короткий способ написать lives = lives - 1.


    Инсайт дня: Списки инициализации vs Присваивание

    В C++ запись : number(number), lives(lives) называется списком инициализации.
    Она записывает данные в переменные до того, как выполнение зайдет в фигурные скобки {} конструктора.

    Почему это важно:
    1. Скорость: Переменные "рождаются" сразу с нужными значениями. Это быстрее, чем сначала создавать их пустыми, а потом заполнять внутри скобок. 2. Пустые скобки: Так как данные уже сохранены через двоеточие, в самих скобках {} делать ничего не нужно. Но по правилам языка они обязаны быть (как точка в конце предложения).

    Вывод: Используй двоеточие для настройки «памяти» класса (инициализации), а тело конструктора оставляй пустым.

    Задача 5: Codewars: "Reversed Strings"

    Complete the solution so that it reverses the string passed into it.

    На русском:

    Допишите решение так, чтобы оно переворачивало строку, переданную в него.

    // Пример использования:
reverseString("world"); // возвращает "dlrow"
reverseString("word");  // возвращает "drow"
    Решение: 
    #include <string>

std::string reverseString(const std::string &str)
{
    // 1. Создаем новую пустую строку для хранения результата
    std::string result = "";

    // 2. Запускаем цикл от последнего индекса к первому.
    // str.size() - 1 — это номер последней буквы.
    // i-- — на каждом шаге уменьшаем индекс на 1.
    for (int i = str.size() - 1; i >= 0; i--)
    {
    // 3. Берем букву под индексом i и «приклеиваем» её в конец result
        result = result + str[i]; // или result += str[i];
    }

    // 4. Возвращаем готовую перевернутую строку
    return result;
}
    На заметку:

    std::string — тип данных (класс) из стандартной библиотеки для работы с текстом.
    [str.size() - 1] — получение индекса последнего символа (так как отсчет идет от 0).
    result += str[i] — оператор, который добавляет символ в конец строки.
    const std::string &str — передача строки в функцию по ссылке (без копирования) и запрет на её изменение.
    int i = str.size() - 1 — сделанно не для удобства счета, а для присвоения определнного индекса к переменной i.


    Инсайт дня: Тип данных vs Имя объекта

    В программировании важно различать тип и конкретную переменную.

    Почему это важно:
    std::string — это название типа (как слово «Машина»), а str — это имя конкретной строки, которую нам дали (как «Твоя машина»). Мы не можем спросить размер у самого понятия «Машина», но можем спросить его у конкретного экземпляра.

    Вывод: Всегда вызывай методы (через точку) у имени переменной (str.size()), а не у названия типа (std::string).

    Задача 6: Codewars: "Return Negative"

    In this simple assignment you are given a number and have to make it negative. But maybe the number is already negative?

    На русском:

    В этом задании вам дается число, и его нужно сделать отрицательным. Но что, если число уже отрицательное? Если число положительное — сделайте его отрицательным. Если оно уже меньше или равно нулю — оставьте как есть.

    // Пример использования:
makeNegative(1);  // возвращает -1
makeNegative(-5); // возвращает -5
makeNegative(0);  // возвращает 0
    Решение: 
    int makeNegative(int num)
{
  // 1. Проверяем, является ли число положительным или нулем.
  if (num >= 0) 
  {
      // 2. Если да, возвращаем его с унарным минусом.
      return -num;
  }

  // 3. Если число уже отрицательное, просто возвращаем его без изменений.
  // Благодаря return выше, блок else нам не требуется.
  return num;
}
    На заметку:

    if — оператор ветвления. Позволяет выполнять код только при соблюдении условия.
    return — оператор выхода из функции. Как только компьютер встречает его, функция завершается.
    Унарный минус (-num) — математический оператор, который меняет знак числа на противоположный.
    Фигурные скобки {} — обязательны, если в if несколько команд. Если команда одна (как в нашем return), скобки можно опустить для краткости.


    Инсайт дня: Early Return (Ранний выход)

    В коде выше мы не использовали else. Если условие if сработало, выполнится первый return, и функция сразу «умрет». До второй строки с return программа просто не доберется.

    Почему это важно:
    Это делает код чище и избавляет от лишних вложенных скобок. Такой подход часто называют «стилем охранника» (Guard Clause): мы сначала проверяем частный случай, а потом спокойно пишем основной код.

    Вывод: Если в блоке if есть return, писать else после него не обязательно.

    Задача 7: Codewars: "Convert boolean values to strings 'Yes' or 'No'"

    Complete the method that takes a boolean value and return a "Yes" string for true, or a "No" string for false.

    На русском:

    Напишите функцию, которая принимает логическое значение (bool) и возвращает строку "Yes", если значение — true, или "No", если значение — false.

    // Пример использования:
bool_to_word(true);  // возвращает "Yes"
bool_to_word(false); // возвращает "No"
    Решение: 
    #include <string>

std::string bool_to_word(bool value)
{
  // 1. Проверяем логическое значение value.
  // Короткая запись if (value) заменяет if (value == true).
  if (value) 
  {
      return "Yes";
  }

  // 2. Если значение false — возвращаем "No".
  // Текст обязательно оборачиваем в двойные кавычки.
  return "No";
}
    На заметку:

    bool — логический тип данных (true или false).
    "Строка" — в C++ текстовые строки всегда пишутся в двойных кавычках. Одинарные кавычки 'a' используются только для одного символа (char).
    if (value) — автоматическая проверка на истинность. Если в скобках true, код внутри сработает.


    Инсайт дня: Краткость логических проверок

    В C++ конструкцию if (value == true) принято сокращать до if (value).

    Почему это важно:
    Оператор if по определению ждет логическое значение. Проверка «равно ли истина истине» — лишнее действие. Это делает код чище и профессиональнее.

    Вывод: Пиши if (value), если проверяешь на правду, и if (!value), если проверяешь на ложь.

    Задача 8: Codewars: "Opposite number"

    Very simple, given a number, find its opposite (additive inverse).

    На русском:

    Очень простая задача: дано число, найдите противоположное ему (аддитивную инверсию).

    // Пример использования:
opposite(1);    // возвращает -1
opposite(-14);  // возвращает 14
    Решение: 
    int opposite(int number) 
{
  // Используем унарный минус, чтобы инвертировать знак.
  // Не забудь поставить точку с запятой в конце!
  return -number; 
}
    На заметку:

    Унарный минус — это оператор -, который применяется к одному операнду. Он меняет знак числа на противоположный (плюс на минус, минус на плюс).
    Точка с запятой ; — в C++ это обязательный символ в конце каждого выражения (инструкции). Без неё код не скомпилируется.


    Инсайт дня: Минус на минус дает плюс

    В программировании работают те же правила математики. Тебе не нужно писать if, чтобы проверять, положительное число или отрицательное. Унарный минус сам превратит -34 в 34.

    Почему это важно:
    Это самый лаконичный способ изменить знак. Тебе не нужны сложные функции — просто один символ перед именем переменной.

    Вывод: Для поиска противоположного числа всегда используй -number. И всегда проверяй наличие ; в конце строки return.

    Задача 9: Codewars: "Vowel Count"

    Return the number (count) of vowels in the given string. We will consider a, e, i, o, u as vowels for this Kata (but not y).

    На русском:

    Верните количество гласных в заданной строке. Мы будем считать a, e, i, o, u гласными для этого ката (но не y). Входная строка будет состоять только из строчных букв и/или пробелов.

    // Пример использования:
getCount("abracadabra"); // возвращает 5
getCount("celebration"); // возвращает 5
    Решение: 
    #include <string>

using namespace std;

int getCount(const string& inputStr) {
  int num_vowels = 0;

  // Используем цикл for для перебора индексов строки
  for (int i = 0; i < inputStr.size(); i++) 
  {
    // Проверяем символ по индексу i на совпадение с гласными
    if (inputStr[i] == 'a' || inputStr[i] == 'e' || inputStr[i] == 'i' || inputStr[i] == 'o' || inputStr[i] == 'u') 
    {
      num_vowels++; 
    }
  }

  return num_vowels;
}
    На заметку:

    Индекс [i] — это адрес конкретной буквы. Переменная i — это просто число, а inputStr[i] позволяет достать букву, которая хранится под этим номером.
    Логическое ИЛИ || — позволяет объединить несколько проверок. Если буква совпала хотя бы с одной гласной, условие сработает.
    Точка с запятой ; — обязательна в конце каждой инструкции (например, после num_vowels++), чтобы компьютер понял, где заканчивается действие.


    Инсайт дня: Индекс — это порядковый номер ящика

    Строка — это ряд ячеек. Чтобы узнать, что внутри, тебе нужен индекс i. Цикл просто перебирает все числа по порядку, а ты открываешь каждый ящик inputStr[i] и проверяешь, лежит ли там гласная.

    Почему это важно:
    Это фундаментальный способ обработки данных в C++. Так ты можешь найти, посчитать или изменить любой символ. Уточнение про (but not y) просто избавляет тебя от необходимости проверять лишнюю букву.

    Вывод: Для решения подобных задач всегда используй связку for и inputStr[i]. Это самый понятный и надежный способ перебора.

    Задача 10: Codewars: "Sum of positive"

    You get an array of numbers, return the sum of all of the positives ones.

    На русском:

    Вы получаете массив чисел, верните сумму всех положительных из них. Если суммировать нечего (массив пуст), сумма по умолчанию равна 0.

    // Пример использования:
[1, -4, 7, 12]  // 1 + 7 + 12 = 20
[-1, -2, -3]    // возвращает 0
    Решение: 
    #include <vector>

int positive_sum(const std::vector<int>& vec) {
  int sum = 0; // Наша копилка

  // Идем по всему вектору
  for (int i = 0; i < vec.size(); i++) 
  {
    // Проверяем: число больше нуля?
    if (vec[i] > 0) 
    {
      // Прибавляем само число к сумме
      sum = sum + vec[i]; 
    }
  }

  // Возвращаем итоговый результат
  return sum;
}
    На заметку:

    std::vector — это динамический массив. Мы работаем с ним так же, как со строкой: через .size() и индекс [i].
    sum = sum + vec[i] — мы не просто считаем количество (1, 2, 3), а берем реальное значение из ячейки и добавляем его в общую кучу.
    Инициализация int sum = 0 — крайне важна. Если не задать ноль в начале, в переменной может оказаться случайный "мусор" из памяти.


    Инсайт дня: Фильтруй и властвуй

    Цикл с условием внутри — это твой персональный фильтр. Ты прогоняешь через него поток данных, но забираешь только то, что подходит под твои правила.

    Почему это важно:
    Это стандартная схема для любой аналитики: найти продажи только за сегодня, посчитать зарплаты только выше нормы и т.д. Логика всегда одна: создаем счетчик -> бежим циклом -> проверяем if -> накапливаем результат.

    Вывод: Для суммирования конкретных элементов всегда используй переменную-накопитель и прибавляй к ней значение через += или sum = sum + значение.

    Задача 11: Codewars: "String repeat"

    Write a function that accepts a non-negative integer n and a string s as parameters, and returns a string of s repeated exactly n times.

    На русском:

    Напишите функцию, которая принимает целое неотрицательное число n и строку s в качестве параметров и возвращает строку s, повторенную ровно n раз.

    // Пример использования:
repeat_str(3, "Abc"); // возвращает "AbcAbcAbc"
repeat_str(5, "Hello"); // возвращает "HelloHelloHelloHelloHello"
    Решение: 
    #include <string>

std::string repeat_str(size_t repeat, const std::string& str) {
  std::string s = ""; // Создаем пустую строку-копилку

  // Цикл сработает ровно столько раз, сколько указано в repeat
  for (size_t i = 0; i < repeat; i++) 
  {
    s = s + str; // Приклеиваем строку str к нашему результату s
  }

  return s; // Возвращаем итоговую склеенную строку
}
    На заметку:

    Оператор += со строками — в C++ это работает как клей. Команда s += str берет текущее содержимое s и дописывает в конец то, что лежит в str.
    Пустая строка "" — мы обязательно инициализируем s пустыми кавычками, чтобы нам было куда "приклеивать" первые символы.
    Цикл по числу — в отличие от прошлых задач, здесь мы не лезем внутрь строки по индексам [i]. Мы используем цикл просто как счетчик повторений (будильник), который заставляет команду склейки сработать нужное количество раз.


    Инсайт дня: Сложение строк — это не математика, а конкатенация

    В C++ знак + умеет не только складывать числа, но и "сшивать" куски текста. Когда ты используешь его внутри цикла, ты по сути занимаешься ручной сборкой длинного слова из одинаковых деталей.

    Почему это важно:
    Это самый простой способ генерировать повторяющиеся данные. Хочешь нарисовать забор из 100 палок? Просто запусти цикл на 100 повторов и делай fence += "|".

    Вывод: Для повторения текста всегда используй пустую строку и цикл for, который будет "наращивать" её длину с каждым кругом.

    Задача 12: Codewars: "Remove First and Last Character"

    It's pretty straightforward. Your goal is to create a function that removes the first and last characters of a string.

    На русском:

    Все довольно просто. Ваша цель — создать функцию, которая удаляет первый и последний символы строки. Вам дана одна строка.

    // Пример использования:
sliceString("eloquent"); // возвращает "loquen"
sliceString("country");  // возвращает "ountr"
    Решение: 
    #include <string>

using namespace std; 

string sliceString(string str)
{
  string result = ""; // Наша пустая "копилка"

  // Начинаем с i = 1 (пропускаем первый символ)
  // Идем до size() - 1 (не доходя до последнего символа)
  for (int i = 1; i < str.size() - 1; i++)
  {
    result += str[i]; // Поэтапно склеиваем буквы в result
  }

  return result; // Отдаем готовую обрезанную строку
}
    На заметку:

    i = 1 — в программировании отсчет идет с нуля. Чтобы пропустить первую букву, мы просто начинаем цикл со второй ячейки (индекс 1).
    str.size() - 1 — это граница. Условие i < str.size() - 1 заставляет цикл остановиться прямо перед последним символом, не включая его.
    Порядок команд — сначала цикл полностью собирает строку в переменную result, и только потом (вне цикла) срабатывает return, который выдает итог.


    Инсайт дня: Границы — это всё

    В этой задаче ты научился управлять "окном" цикла. Ты не просто пробежал по всей строке, а вырезал нужный кусок, просто изменив точку старта и точку финиша в for.

    Почему это важно:
    Умение выставлять правильные границы (i = 1 и size - 1) — это то, что отличает профи от новичка. Это база для работы с любыми подстроками, когда нужно отсечь лишний шум.

    Вывод: Если нужно что-то обрезать, просто подкрути настройки в for (старт; финиш; шаг). Тело цикла останется тем же, а результат изменится.

    Задача 13: Codewars: "Square(n) Sum"

    Complete the square sum function so that it squares each number passed into it and then sums the results together.

    На русском:

    Напишите функцию, которая возводит в квадрат каждое число, переданное в неё, а затем суммирует полученные результаты.

    // Пример использования:
square_sum({1, 2, 2}); // возвращает 9 (1^2 + 2^2 + 2^2 = 9)
square_sum({2, 6});    // возвращает 40 (2^2 + 6^2 = 40)
    Решение: 
    #include <vector>

int square_sum(const std::vector<int>& numbers)
{
  int result = 0; // Создаем хранилище-копилку

  // Цикл проходит по каждому числу в списке по его индексу i
  for (int i = 0; i < numbers.size(); i++)
  {
    // Берем число из ячейки [i], возводим в квадрат и плюсуем к сумме
    result += numbers[i] * numbers[i];
  }

  return result; // Возвращаем накопленную сумму всех квадратов
}
    На заметку:

    Переменная result — это наше хранилище. Она стоит ПЕРЕД циклом, чтобы не обнуляться на каждом шаге и «помнить» всю сумму.
    Оператор += — работает как магнит. Он приклеивает новое значение к тому, что уже лежит в переменной result.
    Индексация [i] — позволяет на каждом круге цикла доставать следующее по счету число из списка numbers.
    Квадрат числа — самый простой способ в C++ — это умножить число на само себя (x * x). Главное — делать это снаружи квадратных скобок.


    Инсайт дня: Цикл — это конвейер, а переменная снаружи — это склад

    В этой задаче важно понимать разделение обязанностей: цикл отвечает за то, чтобы не пропустить ни одно число, а переменная result отвечает за то, чтобы сохранить общую сумму. Если ты используешь просто =, твой "склад" будет постоянно выбрасывать старое содержимое.

    Почему это важно:
    Это классический паттерн "Аккумулятор", который встречается в 90% задач на подсчет данных. Сначала создаем место для хранения, потом наполняем его через итерации.

    Вывод: Всегда инициализируй переменную суммы нулем перед циклом, если планируешь использовать ее для накопления результата.

    Задача 14: Codewars: "Find the smallest integer in the array"

    Your goal is to create a function that finds the smallest integer in the given array.

    На русском:

    Ваша цель — создать функцию, которая находит наименьшее целое число в заданном массиве. Вам дан массив чисел, например {2, 5, 1, 7}.

    // Пример использования:
findSmallest({2, 5, 1, 7}); // возвращает 1
findSmallest({34, 15, 88, 2}); // возвращает 2
    Решение: 
    #include <vector>

using namespace std; 

int findSmallest(vector<int> list)
{
  int result = list[0]; // Берем первое число за эталон (наш "минимум")

  // Пробегаем по всему массиву через индекс i
  for (int i = 0; i < list.size(); i++)
  {
    // Если нашли число меньше того, что лежит в "кармане" result
    if (result > list[i])
    {
      result = list[i]; // Перезаписываем наш минимум новым числом
    }
  }

  return result; // Отдаем самый маленький элемент, когда цикл закончился
}
    На заметку:

    int result = list[0] — важно брать именно первый элемент массива. Если начать с result = 0, а в массиве будут числа {2, 5, 1, 7}, программа выдаст 0, которого нет в списке.
    list[i] — здесь переменная i выступает как индекс. Мы не просто считаем шаги, а используем i как ключ, чтобы достать конкретное число из ячейки массива.
    if (result > list[i]) — это ядро алгоритма. Мы обновляем result только в том случае, если текущий кандидат реально "побил" предыдущий рекорд минимальности.


    Инсайт дня: Сравнение — ключ к поиску

    В этой задаче ты научился не просто перебирать цикл, а заставил программу принимать решения на каждом шагу. Ты создал алгоритм "сита", через которое проходят все числа, но в итоге остается только одно — самое мелкое.

    Почему это важно:
    Поиск минимума или максимума — это фундамент. По такому же принципу работают фильтры цен в интернет-магазинах, поиск самого дешевого билета или самого короткого пути в навигаторе.

    Вывод: Чтобы найти лучшее (или наименьшее), нужно иметь эталон для сравнения и проверить каждого кандидата до самого конца списка.

    Ваша цель — создать функцию, которая возвращает приветствие. Программа должна выдать классическую фразу "hello world".

    // Пример использования:
greet(); // возвращает "hello world"
    Решение: 
    #include <string>

std::string greet() 
{

  return "hello world"; 
}
    На заметку:

    std::string — тип данных перед именем функции. Он обязывает нас вернуть именно текст.

    Инсайт дня: Результат важнее процесса

    В этой задаче ты четко разделил вывод на экран (printf) и возврат значения (return). Для решения задач на Codewars важен именно возврат — это то, что компьютер передает другой программе.

    Почему это важно:
    В реальной разработке функции постоянно общаются друг с другом. Одна функция находит имя игрока, делает return, а вторая подхватывает этот результат и рисует его в интерфейсе. Это основа модульного кода.

    Вывод: Если функция что-то "обещала" (например, string или int), она обязана это вернуть через return в конце.
