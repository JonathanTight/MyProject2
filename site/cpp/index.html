    Задача 1: "Two Sum"

    Write a function that takes an array of numbers (integers for the tests) and a target number. It should find two different items in the array that, when added together, give the target value. The indexes of these items should then be returned in a tuple / list (depending on your language) like so: (index1, index2).

    For the purposes of this kata, some tests may have multiple answers; any valid solutions will be accepted.

    The input will always be valid (numbers will be an array of length 2 or greater, and all of the items will be numbers; target will always be the sum of two different items from that array).

    Примечание: Хотя в задаче просят "tuple", в C++ для пары значений лучше всего подходит std::pair.

    На русском:

    Напишите функцию, которая принимает массив чисел (целых чисел для тестов) и целевое число (target). Она должна найти в массиве два разных элемента, которые при сложении дают целевое значение. Индексы этих элементов должны быть возвращены в виде пары (tuple/list) вот так: (index1, index2).

    В рамках этого ката некоторые тесты могут иметь несколько вариантов ответа; любой правильный ответ будет принят.

    Входные данные всегда корректны: массив длиной 2 или более, все элементы — числа; target всегда является суммой двух разных элементов из этого массива.

    Примеры данных:

two_sum({1, 2, 3}, 4); // returns {0, 2} or {2, 0}
two_sum({3, 2, 4}, 6); // returns {1, 2} or {2, 1}
    Решение: 
    #include <vector>

std::pair<std::size_t, std::size_t> two_sum(const std::vector<int>& numbers, int target) {
    for (std::size_t i = 0; i < numbers.size(); ++i) {
        for (std::size_t j = i + 1; j < numbers.size(); ++j) {
            if (numbers[i] + numbers[j] == target) {
                return {i, j};
            }
        }
    }
    return {0, 0};
}
    На заметку:

    #include <vector> — это подключение стандартной библиотеки для работы с динамическими массивами (векторами).
    Зачем: Без этой строки компилятор не поймет, что такое std::vector, и выдаст ошибку.
    Почему на Codewars его нет: На Codewars этот заголовок (и другие базовые) часто уже скрыто подключен за кулисами в тестовой среде для удобства, чтобы ты писал только саму функцию. В реальном проекте в VS Code его обязательно нужно писать самому в начале файла.


    Инсайт дня: Индексы vs Размер (Off-by-one error)

    Индекс (Index) — это смещение (дистанция) от начала. От первого элемента до него самого — 0 шагов. Поэтому первый элемент имеет индекс 0.
    Размер (Size) — это общее количество штук. Если в массиве есть хотя бы один предмет, его размер — 1.
    В векторе размером N последний доступный индекс всегда равен N - 1.

    Пример:
    Если numbers.size() == 5, то:
    Элементы: 1-й, 2-й, 3-й, 4-й, 5-й.
    Индексы: 0, 1, 2, 3, 4.
    Попытка обратиться к numbers[5] приведет к ошибке, так как индекса 5 не существует.

    Вывод: Всегда помнить, что цикл должен идти до i < size, а не i <= size.

    Задача 2: "Even or Odd"

    Create a function that takes an integer as an argument and returns "Even" for even numbers or "Odd" for odd numbers.

    На русском:

    Создайте функцию, которая принимает целое число в качестве аргумента и возвращает "Even" (Четное) для четных чисел или "Odd" (Нечетное) для нечетных.

    Примеры данных:

even_or_odd(2);    // returns "Even"
even_or_odd(7);    // returns "Odd"
even_or_odd(-42);  // returns "Even"
    Решение: 
    #include <string>

std::string even_or_odd(int number) 
{
  if (number % 2 == 0) {
    return "Even";
  } else {
    return "Odd";
  }
}
    На заметку:

    std::string — это тип возвращаемого значения функции, так как мы возвращаем слова, а не числа.
    Синтаксис if/else: условие всегда пишется в круглых скобках (), а блоки кода — в фигурных {}. Каждая команда внутри заканчивается точкой с запятой ;.


    Инсайт дня: Оператор остатка от деления (%)

    Оператор % (modulo) возвращает то, что осталось после деления одного целого числа на другое.
    Если число % 2 == 0, значит оно делится на два нацело — это главный способ определить четность в программировании.

    Пример:
    Если number == 7, то 7 % 2 даст 1. Результат не 0, значит число нечетное.
    Если number == 8, то 8 % 2 даст 0. Результат 0, значит число четное.

    Вывод: Любая задача, где нужно проверить кратность одного числа другому, решается через оператор %.

    На русском:

    Нам нужна функция, которая может преобразовать число (целое число) в строку. Какие способы решения этой задачи вы знаете?

    ```cpp

    Примеры данных:

    123  --> "123"
999  --> "999"
-100 --> "-100"
```
    Решение: 
    #include <string>

std::string number_to_string(int num) {
  return std::to_string(num);
}
    На заметку:

    #include <string> — необходимо подключить, чтобы использовать функцию std::to_string().
    std::to_string() — принимает числовые типы (int, float, double) и возвращает их строковое представление (std::string). Это самый простой и современный способ конвертации в C++.


    Инсайт дня: Строка vs Число (Типизация)

    Число (int) — это значение, с которым можно проводить математические операции (сложение, умножение).
    Строка (string) — это набор символов (текст). Даже если в строке написано "123", компьютер воспринимает это как последовательность символов, а не как число.

    Пример:
    Если num = 123, то 123 + 1 даст результат 124.
    Если мы работаем со строкой "123", то попытка прибавить к ней "1" приведет к склейке текста — "1231".

    Вывод: Всегда следи за типами данных: для расчетов используй int, для вывода текста или хранения строковых ID — string.

    Задача 4: "Guess the Number Game"

    Imagine you are creating a game where the user has to guess the correct number. But there is a limit of how many guesses the user can do.

    If the user tries to guess more than the limit, the function should throw an error. If the user guess is right it should return true. If the user guess is wrong it should return false and lose a life. Can you finish the game so all the rules are met?

    На русском:

    Представьте, что вы создаете игру, в которой пользователь должен угадать правильное число. Но количество попыток (догадок), которые может сделать пользователь, ограничено. Если пользователь пытается угадать больше раз, чем позволяет лимит, функция должна выбросить ошибку. Если догадка пользователя верна, функция должна вернуть true. Если догадка неверна, функция должна вернуть false и пользователь теряет одну жизнь. Можете ли вы дописать игру так, чтобы соблюдались все эти правила?

    // Пример использования:
Guesser game(10, 2); 
game.guess(10); // возвращает true
game.guess(1);  // возвращает false, осталась 1 жизнь
game.guess(1);  // возвращает false, жизней 0
game.guess(1);  // выбрасывает std::runtime_error
    Решение: 
    #include <stdexcept>

class Guesser
{
public:
    // Конструктор инициализирует начальные значения через список инициализации
    Guesser(int number, int lives)
      : number(number), lives(lives)
    { }

    bool guess(int n)
    {
        // 1. Проверяем наличие жизней ПЕРЕД ходом. 
        // Если их 0 или меньше — бросаем ошибку.
        if (lives <= 0) {
            throw std::runtime_error("Expect error: already dead");
        }

        // 2. Проверяем, угадано ли число (сравниваем n и number)
        if (n == number) {
            return true;
        }

        // 3. Если не угадал — уменьшаем жизни и возвращаем false
        // Сюда код дойдет, только если условия выше не сработали.
        lives--;
        return false;
    }

private:
    int number, lives; // Память объекта (приватные переменные)
};
    На заметку:

    #include <stdexcept> — библиотека для работы со стандартными исключениями (ошибками).
    throw std::runtime_error("текст") — команда, которая мгновенно прерывает работу функции и сообщает о критической ошибке.
    lives-- — декремент. Короткий способ написать lives = lives - 1.


    Инсайт дня: Списки инициализации vs Присваивание

    В C++ запись : number(number), lives(lives) называется списком инициализации.
    Она записывает данные в переменные до того, как выполнение зайдет в фигурные скобки {} конструктора.

    Почему это важно:
    1. Скорость: Переменные "рождаются" сразу с нужными значениями. Это быстрее, чем сначала создавать их пустыми, а потом заполнять внутри скобок. 2. Пустые скобки: Так как данные уже сохранены через двоеточие, в самих скобках {} делать ничего не нужно. Но по правилам языка они обязаны быть (как точка в конце предложения).

    Вывод: Используй двоеточие для настройки «памяти» класса (инициализации), а тело конструктора оставляй пустым.

    Задача 5: "Reversed Strings"

    Complete the solution so that it reverses the string passed into it.

    На русском:

    Допишите решение так, чтобы оно переворачивало строку, переданную в него.

    // Пример использования:
reverseString("world"); // возвращает "dlrow"
reverseString("word");  // возвращает "drow"
    Решение: 
    #include <string>

std::string reverseString(const std::string &str)
{
    // 1. Создаем новую пустую строку для хранения результата
    std::string result = "";

    // 2. Запускаем цикл от последнего индекса к первому.
    // str.size() - 1 — это номер последней буквы.
    // i-- — на каждом шаге уменьшаем индекс на 1.
    for (int i = str.size() - 1; i >= 0; i--)
    {
    // 3. Берем букву под индексом i и «приклеиваем» её в конец result
        result = result + str[i]; // или result += str[i];
    }

    // 4. Возвращаем готовую перевернутую строку
    return result;
}
    На заметку:

    std::string — тип данных (класс) из стандартной библиотеки для работы с текстом.
    [str.size() - 1] — получение индекса последнего символа (так как отсчет идет от 0).
    result += str[i] — оператор, который добавляет символ в конец строки.
    const std::string &str — передача строки в функцию по ссылке (без копирования) и запрет на её изменение.
    int i = str.size() - 1 — сделанно не для удобства счета, а для присвоения определнного индекса к переменной i.


    Инсайт дня: Тип данных vs Имя объекта

    В программировании важно различать тип и конкретную переменную.

    Почему это важно:
    std::string — это название типа (как слово «Машина»), а str — это имя конкретной строки, которую нам дали (как «Твоя машина»). Мы не можем спросить размер у самого понятия «Машина», но можем спросить его у конкретного экземпляра.

    Вывод: Всегда вызывай методы (через точку) у имени переменной (str.size()), а не у названия типа (std::string).

    Задача 6: "Return Negative"

    In this simple assignment you are given a number and have to make it negative. But maybe the number is already negative?

    На русском:

    В этом задании вам дается число, и его нужно сделать отрицательным. Но что, если число уже отрицательное? Если число положительное — сделайте его отрицательным. Если оно уже меньше или равно нулю — оставьте как есть.

    // Пример использования:
makeNegative(1);  // возвращает -1
makeNegative(-5); // возвращает -5
makeNegative(0);  // возвращает 0
    Решение: 
    int makeNegative(int num)
{
  // 1. Проверяем, является ли число положительным или нулем.
  if (num >= 0) 
  {
      // 2. Если да, возвращаем его с унарным минусом.
      return -num;
  }

  // 3. Если число уже отрицательное, просто возвращаем его без изменений.
  // Благодаря return выше, блок else нам не требуется.
  return num;
}
    На заметку:

    if — оператор ветвления. Позволяет выполнять код только при соблюдении условия.
    return — оператор выхода из функции. Как только компьютер встречает его, функция завершается.
    Унарный минус (-num) — математический оператор, который меняет знак числа на противоположный.
    Фигурные скобки {} — обязательны, если в if несколько команд. Если команда одна (как в нашем return), скобки можно опустить для краткости.


    Инсайт дня: Early Return (Ранний выход)

    В коде выше мы не использовали else. Если условие if сработало, выполнится первый return, и функция сразу «умрет». До второй строки с return программа просто не доберется.

    Почему это важно:
    Это делает код чище и избавляет от лишних вложенных скобок. Такой подход часто называют «стилем охранника» (Guard Clause): мы сначала проверяем частный случай, а потом спокойно пишем основной код.

    Вывод: Если в блоке if есть return, писать else после него не обязательно.

    Задача 7: "Convert boolean values to strings 'Yes' or 'No'"

    Complete the method that takes a boolean value and return a "Yes" string for true, or a "No" string for false.

    На русском:

    Напишите функцию, которая принимает логическое значение (bool) и возвращает строку "Yes", если значение — true, или "No", если значение — false.

    // Пример использования:
bool_to_word(true);  // возвращает "Yes"
bool_to_word(false); // возвращает "No"
    Решение: 
    #include <string>

std::string bool_to_word(bool value)
{
  // 1. Проверяем логическое значение value.
  // Короткая запись if (value) заменяет if (value == true).
  if (value) 
  {
      return "Yes";
  }

  // 2. Если значение false — возвращаем "No".
  // Текст обязательно оборачиваем в двойные кавычки.
  return "No";
}
    На заметку:

    bool — логический тип данных (true или false).
    "Строка" — в C++ текстовые строки всегда пишутся в двойных кавычках. Одинарные кавычки 'a' используются только для одного символа (char).
    if (value) — автоматическая проверка на истинность. Если в скобках true, код внутри сработает.


    Инсайт дня: Краткость логических проверок

    В C++ конструкцию if (value == true) принято сокращать до if (value).

    Почему это важно:
    Оператор if по определению ждет логическое значение. Проверка «равно ли истина истине» — лишнее действие. Это делает код чище и профессиональнее.

    Вывод: Пиши if (value), если проверяешь на правду, и if (!value), если проверяешь на ложь.

    Задача 8: "Opposite number"

    Инсайт дня: Порядок действий имеет значение

    В строке c = std::toupper(c) компьютер сначала вычисляет то, что справа (делает букву большой), а только потом записывает результат в то, что слева.

    Почему это важно:
    Знак = в программировании — это не равенство, а команда «присвоить». Сначала мы готовим «товар» (справа), а потом кладем его в «коробку» (слева). Понимание этого порядка — ключ к чтению любого кода.

    Best Practices:

#include <algorithm>
#include <cctype>

std::string makeUpperCase(std::string str) {
  // Используем стандартный алгоритм для прохода по всей строке
  std::transform(str.begin(), str.end(), str.begin(), 
                 [](unsigned char c) { return std::toupper(c); });
  return str;
}
    Использование std::transform из библиотеки <algorithm> считается более «взрослым» способом. Это избавляет от написания циклов вручную и сводит задачу к одной строчке кода.

std::vector<std::string> solution(const std::string &s)
{
  std::vector<std::string> result;

  // 1. Проходим циклом по строке с шагом 2
  for (int i = 0; i < s.size(); i += 2) {

    // 2. Создаем временную строку для текущей пары

    string s = to_string(num);

        int digit = bukva - '0';

    Инсайт дня: Потоковое чтение против ручного парсинга

    Использование stringstream избавляет от необходимости вручную искать пробелы, резать строку на подстроки и проверять знаки минус у отрицательных чисел. Поток сам понимает, где кончается одно число и начинается другое.

    Инициализация min и max первым прочитанным числом защищает от ошибок. Если вместо этого использовать 0, код сработает неверно на строке, состоящей только из отрицательных чисел (например, "-5 -10 -3" ошибочно выдаст максимум 0).

    Вывод: Для разбора строк с неизвестным количеством чисел, разделенных пробелами или табами, stringstream — самый надежный и лаконичный инструмент в C++.

    #include <string>
#include <sstream>
#include <climits>

std::string highAndLow(const std::string& numbers) {
    std::stringstream ss(numbers);
    int i, min = INT_MAX, max = INT_MIN;
    while (ss >> i) {

        if (i > max) max = i;

}

    Задача 42: "Find the odd int"

    Given an array of integers, find the one that appears an odd number of times.

    There will always be only one integer that appears an odd number of times.

    На русском:

    Дан массив целых чисел. Найдите то число, которое встречается нечетное количество раз. В массиве всегда будет только одно такое число.

    // Пример использования:
findOdd({7});                                   // => returns 7 (встречается 1 раз)
findOdd({0, 1, 0, 1, 0});                       // => returns 0 (встречается 3 раза)
findOdd({1, 2, 2, 3, 3, 3, 4, 3, 3, 3, 2, 2, 1}); // => returns 4 (встречается 1 раз)
    Решение: 
    #include <vector>

int findOdd(const std::vector<int>& numbers){
    int a = 0;

    // Перебираем все элементы массива и применяем XOR
    for (int i = 0; i < numbers.size(); i++) {
        a ^= numbers[i];
    }

    return a;
}
    На заметку:

    ^= — оператор побитового исключающего ИЛИ (XOR) с присваиванием. Строка a ^= numbers[i]; эквивалентна a = a ^ numbers[i];.
    A ^ A = 0 — фундаментальное свойство XOR. Любое число, примененное само к себе через эту операцию, уничтожает себя и дает ноль.
    A ^ 0 = A — любое число при операции с нулем остается неизменным.
    Порядок операций — для XOR порядок не имеет значения (A ^ B ^ A превратится в 0 ^ B, что равно B). Это позволяет «гасить» парные числа, в каком бы месте массива они ни находились.


    Инсайт дня: Низкоуровневая магия железа против лишней памяти

    Использование побитовой операции XOR позволяет решить задачу за один единственный проход по массиву, не используя массивы-счетчики, сортировку или сложные структуры данных для подсчета частоты.

    Почему это важно:
    Все числа, которые встречаются четное количество раз, гарантированно уничтожат друг друга в процессе вычислений (превратятся в 0). В переменной-аккумуляторе останется только то единственное число, у которого не оказалось пары. Это дает максимальную скорость работы алгоритма (O(N) по времени) и нулевые затраты по оперативной памяти (O(1) по памяти).

    Вывод: Для поиска одиночных элементов среди парных дубликатов побитовый XOR — самый быстрый, эффективный и элегантный инструмент в C++.

    Best Practices: 

    #include <vector>

int findOdd(const std::vector<int>& numbers) {
    int a = 0;
    for (auto const& num : numbers) {
        a ^= num;
    }
    return a;
}
    Этот подход использует современный цикл range-based for (for-each). Он избавляет код от ручной работы с индексами [i] и проверок numbers.size(). Конструкция auto const& num автоматически и безопасно берет каждый элемент массива по очереди, делая код чище и защищая от случайного выхода за границы памяти.

    Задача 43: "Descending Order"

    Your task is to make a function that can take any non-negative integer as an argument and return it with its digits in descending order. Essentially, rearrange the digits to create the highest possible number.

    На русском:

    Напишите функцию, которая принимает любое неотрицательное целое число и возвращает его же, но так, чтобы все цифры были отсортированы по убыванию (от большей к меньшей). Фактически, нужно составить максимально возможное число из этих цифр.

    // Пример использования:
descendingOrder(42145);  // => returns 54421
descendingOrder(145263); // => returns 654321
descendingOrder(123456); // => returns 654321
    Решение: 
    #include <cinttypes>
#include <string>
#include <utility> // Для функции std::swap

uint64_t descendingOrder(uint64_t a)
{
    std::string res = std::to_string(a);

    // Сортировка пузырьком (Bubble Sort) по убыванию
    for (size_t i = 0; i < res.size(); i++) {
        for (size_t j = i + 1; j < res.size(); j++) {
            if (res[i] < res[j]) {
                std::swap(res[i], res[j]);
            }
        }
    }

    return std::stoull(res);
}
    На заметку:

    uint64_t — строго 64-битное целое положительное число. Используется, когда нужно гарантировать одинаковый огромный размер переменной на любых процессорах.
    std::to_string — превращает число в строку std::string, что позволяет работать с отдельными цифрами как с символами.
    res[i] < res[j] — проверка порядка. Если левая цифра меньше правой, значит, они стоят не по убыванию и их нужно поменять местами.
    std::swap — встроенная функция, которая эффективно меняет содержимое двух ячеек памяти местами.
    std::stoull — переводит строку обратно в 64-битное беззнаковое число (unsigned long long), предотвращая переполнение памяти.


    Инсайт дня: Строковый парсинг против математических разрядов

    Перевод числа в строковый формат перед сортировкой избавляет от необходимости вручную разбирать число на разряды через деление на 10, сохранять их в промежуточные массивы, а затем собирать число обратно через умножение.

    Почему это важно:
    При работе с огромными 64-битными числами (до 18 квинтиллионов) ручная математическая сборка перевернутого числа может легко привести к ошибкам переполнения типов данных на промежуточных этапах. Строка выступает безопасным и наглядным буфером, где каждая цифра изолирована в своей ячейке памяти.

    Вывод: Когда задача требует перегруппировать, отсортировать или переставить цифры внутри числа, самый безопасный и читаемый путь в C++ — временно превратить число в std::string.

    Best Practices: 

    #include <cinttypes>
#include <string>
#include <algorithm>

uint64_t descendingOrder(uint64_t a) {
    std::string s = std::to_string(a);

    // Сортировка с использованием обратных итераторов (по убыванию)
    std::sort(s.rbegin(), s.rend());

    return std::stoull(s);
}
    Этот подход считается ультимативным лучшим решением, так как вместо ручных вложенных циклов использует встроенную эффективную функцию std::sort. Обратные итераторы rbegin() и rend() заставляют алгоритм сортировать контейнер «задом наперед» (от большего к меньшему), избавляя от необходимости подключать библиотеку <functional> для использования флага std::greater.

    Задача 44: "Stop gninnipS My sdroW!"

    Your task is to make a function that takes in a string of one or more words, and returns the same string, but with all words that have five or more letters reversed (just like the name of this kata). Strings passed in will consist of only letters and spaces. Spaces will be included only when more than one word is present.

    На русском:

    Напишите функцию, которая принимает строку, состоящую из одного или нескольких слов, и возвращает ту же строку, но с перевернутыми словами, длина которых составляет пять или более букв. Входные строки содержат только буквы и пробелы. Пробелы добавляются только тогда, когда в строке присутствует более одного слова.

    // Пример использования:
spinWords("Hey fellow warriors");  // => returns "Hey wollef sroirraw"
spinWords("This is a test");        // => returns "This is a test"
spinWords("This is another test"); // => returns "This is rehtona test"
    Решение: 
    #include <string>
#include <algorithm> // Для функции std::reverse

std::string spinWords(const std::string &str)
{
    std::string result = "";
    std::string s = "";

    for (size_t i = 0; i < str.size(); i++) {
        if (str[i] != ' ') {
            s += str[i];
        } else {
            // Если встретили пробел, проверяем длину накопленного слова
            if (s.size() >= 5) {
                std::reverse(s.begin(), s.end());
            }
            result += s + " ";
            s = ""; // Очищаем буфер для следующего слова
        }
    }

    // Обработка последнего слова после выхода из цикла (так как в конце строки нет пробела)
    if (s.size() >= 5) {
        std::reverse(s.begin(), s.end());
    }
    result += s;

    return result;
}
    На заметку:

    std::reverse — стандартная функция, переворачивающая элементы в заданном диапазоне (изменяет саму строку s на месте).
    s.size() >= 5 — ключевое условие задачи. Проверяет, состоит ли текущее слово из пяти или более символов.
    result += s + " " — конкатенация строк. Добавляет обработанное слово и возвращает пробел на место в результирующую строку.
    s = "" — операция сброса строкового буфера. Необходима, чтобы буквы нового слова не приклеивались к концу предыдущего.
    result += s — финальное добавление хвоста строки вне цикла. Защищает алгоритм от потери последнего слова, за которым не следовал пробел.


    Инсайт дня: Логика граничных условий в посимвольном парсинге

    При ручном разборе строки посимвольно (через цикл for) триггером для окончания обработки слова обычно выступает разделитель — в данном случае пробел. Однако реальные текстовые строки практически никогда не заканчиваются пробелом, они заканчиваются концом самой строки (\0).

    Почему это важно:
    Если забыть обработать накопленный буфер s сразу после завершения цикла, программа совершит критическую логическую ошибку — «потеряет» последнее слово строки. Ввод "Hey warriors" вернет только "Hey ", так как слово "warriors" останется заблокированным внутри переменной s.

    Вывод: При написании кастомных парсеров, завязанных на символы-разделители, всегда проверяйте состояние буферов после выхода из основного цикла. Последний элемент коллекции всегда требует индивидуальной ручной доработки.

    Best Practices: 

    #include <string>
#include <sstream>
#include <algorithm>

std::string spinWords(const std::string &str) {
    std::stringstream ss(str);
    std::string word;
    std::string result = "";

    while (ss >> word) {
        if (word.length() >= 5) {
            std::reverse(word.begin(), word.end());
        }
        if (!result.empty()) {
            result += " "; // Добавляем пробел перед каждым словом, кроме первого
        }
        result += word;
    }

    return result;
}
    Данный подход является эталонным для C++. Использование std::stringstream элегантно решает проблему «последнего слова», так как строковый поток самостоятельно извлекает слова по пробелам и корректно завершает цикл while, когда поток пустеет. Проверка !result.empty() избавляет от появления лишних пробелов в начале или конце итоговой строки.

    Задача 45: "You're a square!"

    A square of squares. You like building blocks. You especially like building blocks that are squares. And what you even like more, is to arrange them into a square of square building blocks! Task: Given an integral number, determine if it's a square number.

    На русском:

    Напишите функцию, которая принимает целое число и определяет, является ли оно полным квадратом. Полный квадрат (или квадратное число) — это целое число, которое является квадратом другого целого числа. Простыми словами: это результат умножения какого-то целого числа на самого себя.

    // Пример использования:
is_square(-1); // => returns false
is_square(0);  // => returns true
is_square(3);  // => returns false
is_square(4);  // => returns true
is_square(25); // => returns true
is_square(26); // => returns false
    Решение: 
    #include <cmath> // Для функции std::sqrt

bool is_square(int n) {
    // Отрицательные числа не могут быть полными квадратами
    if (n < 0) {
        return false;
    }

    // Извлекаем корень и отбрасываем дробную часть при записи в int
    int root = std::sqrt(n);

    // Проверяем, вернет ли обратное умножение исходное число
    return root * root == n;
}
    На заметку:

    bool — логический тип данных, который может принимать только два значения: true (истина) или false (ложь).
    n < 0 — обязательный защитный барьер. Без него функция std::sqrt от отрицательного числа вернет NaN, что приведет к ошибкам компилятора или неверным результатам тестов.
    std::sqrt — встроенная функция, которая высчитывает квадратный корень из числа. Для 25 вернет 5.0, для 26 вернет 5.099....
    int root — целочисленная переменная. При сохранении в нее дробного результата функции sqrt, язык C++ принудительно отсекает (а не округляет) всю дробную часть. Из 5.099 получится чистая 5.
    root * root == n — проверка «честности» корня. Мы умножаем полученное целое число само на себя и сверяем с оригиналом.


    Инсайт дня: Опасность "NaN" при работе с математическими функциями

    Передача отрицательного аргумента в функцию извлечения корня std::sqrt() — классическая уязвимость в C++. Математически корень из минус единицы не определен среди действительных чисел, поэтому функция возвращает значение NaN (Not a Number). Почему это важно: При попытке насильно преобразовать NaN в целое число int, в коде возникает неопределенное поведение (undefined behavior). Разные компиляторы обрабатывают это по-разному: один превратит его в ноль (и тогда 0 * 0 == 0 ошибочно вернет true для отрицательного числа), а другой выдаст критический сбой памяти.

    Вывод: При работе со стандартными математическими библиотеками всегда делайте предварительную валидацию входных данных (аргументов) до того, как передать их в функцию.

    Best Practices: 

    #include <cmath>

bool is_square(int n) {
    // Короткая однострочная запись с ленивым вычислением
    return n >= 0 && (int)std::sqrt(n) * (int)std::sqrt(n) == n;
}
    Этот подход считается ультимативным коротким решением. Логический оператор && (И) в C++ работает по «ленивому» принципу (short-circuit evaluation): если первая часть условия n >= 0 оказывается ложной, то вторая часть с функцией std::sqrt даже не начинает вычисляться. Это гарантирует стопроцентную безопасность кода и защиту от передачи отрицательных чисел в корень.

    Задача 46: "Sum of Digits / Digital Root"

    Digital root is the recursive sum of all the digits in a number. Given n, take the sum of the digits of n. If that value has more than one digit, continue reducing in this way until a single-digit number is produced. The input will be a non-negative integer.

    На русском:

    Напишите функцию, которая принимает целое неотрицательное число и вычисляет его цифровой корень. Полный цифровой корень — это однозначное число, полученное в результате повторяющегося сложения всех цифр исходного числа, пока не останется одна цифра.

    // Пример использования:
digital_root(16);      // => returns 7
digital_root(942);     // => returns 6
digital_root(132189);  // => returns 6
digital_root(493193);  // => returns 6
    Решение: 
    int digital_root(int n) {
// Внешний цикл: крутится до тех пор, пока число n не станет однозначным (меньше 10)
while (n >= 10) {
    int res = 0; // Переменная-копилка для суммы цифр на текущем круге

    // Внутренний цикл: полностью разбирает число n по цифрам и складывает их
    while (n > 0) {
        res += n % 10; // Забираем последнюю цифру в res
        n = n / 10;    // Отрезаем её от числа n
    }

    // Переносим полученную сумму res обратно в n для следующей проверки
    n = res; 
}

// Как только число n упало ниже 10, цикл завершается и функция возвращает результат
return n; 
}
    На заметку:

    while (n >= 10) — главный управляющий цикл. Он гарантирует, что программа не закроется раньше времени, если после первого подсчета сумма цифр все еще осталась двузначной (например, из огромного числа получилось 18, а не 9). int res = 0 — переменная создается заново на каждом круге внешнего цикла. Это важно, чтобы сумма цифр каждый раз считалась с чистого листа, а не прибавлялась к старым результатам. n % 10 — операция взятия остатка от деления на 10. В C++ это самый надежный способ достать крайнюю правую цифру любого целого числа. n = n / 10 — целочисленное деление на 10. Поскольку n имеет тип int, дробная часть просто отбрасывается. Это позволяет «стереть» уже посчитанную последнюю цифру и сдвинуть число влево. n = res — ключевой трюк алгоритма. Мы заменяем старое число новой суммой его цифр и отправляем его на повторную проверку в условие n >= 10.


    Инсайт дня: Вложенные циклы как инструмент пошагового сжатия данных

    Использование одного цикла внутри другого — это классический паттерн «матрешки» в программировании. Внутренний цикл выполняет простую локальную работу (схлопывает число 942 в 15), а внешний цикл контролирует глобальный бизнес-процесс (спрашивает: «Результат уже готов или нужно запустить схлопывание еще раз?»). Понимание того, как внутренний цикл передает свои результаты внешнему через переменную n = res, избавляет от необходимости писать три, четыре или десять одинаковых блоков кода вручную.

    Вывод: Если вам нужно повторять одну и ту же операцию неизвестное количество раз до достижения конкретного критерия (например, пока число не станет маленьким), всегда оборачивайте рабочий цикл в еще один контролирующий цикл while.

    Best Practices: 
    int digital_root(int n) {
// Ультимативное математическое решение без использования циклов
return (n - 1) % 9 + 1;
}

    Этот подход считается ультимативным коротким решением. В высшей математике этот алгоритм называется цифровым вычетом по модулю 9. Из-за особенностей десятичной системы счисления, остаток от деления любого числа на 9 совпадает с суммой его цифр. Формула (n - 1) % 9 + 1 идеально обрабатывает абсолютно любые числа за одну микросекунду, избегая бесконечных циклов и полностью решая проблему чисел, кратных девяти (для которых обычный оператор % 9 возвращал бы ошибочный 0 вместо 9).

    Задача 47: "Get the Middle Character"

    You are going to be given a non-empty string. Your job is to return the middle character(s) of the string. If the string's length is odd, return the middle character. If the string's length is even, return the middle 2 characters.

    На русском:

    Напишите функцию, которая принимает непустую строку и возвращает её центральный символ (или символы). Если длина строки нечетная, нужно вернуть один средний символ. Если длина четная — верните два средних символа.

    // Пример использования:
get_middle("test");    // => returns "es"
get_middle("testing"); // => returns "t"
get_middle("middle");  // => returns "dd"
get_middle("A");       // => returns "A"
    Решение: 
    #include <string>

std::string get_middle(std::string input) {
    // Проверяем, четное ли количество букв в слове
    if (input.size() % 2 == 0) {
        // Для четной длины: берем 2 символа, начиная с позиции (середина - 1)
        return input.substr((input.size() / 2) - 1, 2);
    } else {
        // Для нечетной длины: берем 1 символ из самой середины
        return input.substr(input.size() / 2, 1);
    }
}
    На заметку:

    input.size() — встроенный метод, который возвращает общее количество символов в строке.
    % 2 == 0 — проверка на четность с помощью оператора остатка от деления (%). Обрати внимание на два знака равенства == — в C++ это строгая проверка на равенство, а не присваивание =.
    input.size() / 2 — целочисленное деление. В C++ при делении целых чисел дробная часть отбрасывается. Например, для строки из 7 символов 7 / 2 даст ровно 3.
    input.substr() — функция вырезания подстроки. Принимает два аргумента: (откуда_начать, сколько_символов_взять). Эти два числа никак не связаны между собой: левое вычисляет индекс старта, а правое жестко ограничивает длину вырезки (1 для нечетных, 2 для четных).


    Инсайт дня: Ловушка путаницы присваивания (=) и сравнения (==)

    Использование одиночного знака = вместо двойного == внутри условий if — одна из главных причин багов у новичков в C++. Одиночный знак = принудительно перезаписывает значение переменной, в то время как == просто сравнивает левую и правую части, возвращая true или false. Почему это важно: Если случайно написать if (x = 0), компилятор запишет 0 в переменную x, а само условие if посчитает ложным (так как ноль в C++ эквивалентен false). Код скомпилируется без явных ошибок, но логика программы полностью сломается. Вывод: Всегда внимательно проверяйте условия if: для проверки равенства обязаны стоять два символа ==.

    Best Practices: 

    #include <string>

std::string get_middle(std::string input) {
    // Короткая запись в одну строчку через тернарный оператор
    return input.substr((input.size() - 1) / 2, 2 - (input.size() % 2));
}
    Этот подход использует чистую математику для устранения условий if-else. Выражение (input.size() - 1) / 2 автоматически находит правильный стартовый индекс как для четной, так и для нечетной длины строки благодаря правилам целочисленного деления C++. Длина вырезаемой части регулируется формулой 2 - (input.size() % 2): если длина четная, остаток равен 0 и вырезается 2 символа; если нечетная — остаток равен 1 и вырезается 1 символ. Это делает код максимально компактным и производительным.

    Задача 48: "Isogram"

    An isogram is a word that has no repeating letters, consecutive or non-consecutive. Implement a function that determines whether a string that contains only letters is an isogram. Assume the empty string is an isogram. Ignore letter case.

    На русском:

    Напишите функцию, которая проверяет, является ли слово изограммой. Изограмма — это слово, в котором нет повторяющихся букв, независимо от того, стоят они рядом или в разных частях слова. Функция должна игнорировать регистр букв (большие и маленькие буквы считаются одинаковыми). Пустая строка считается изограммой.

    // Пример использования:
is_isogram("Dermatoglyphics"); // => returns true
is_isogram("aba");             // => returns false
is_isogram("moOse");           // => returns false (регистр игнорируется)
    Решение: 
    #include <string>
#include <cctype>

bool is_isogram(const std::string& str) {
    for (size_t i = 0; i < str.size(); i++) {
        for (size_t j = i + 1; j < str.size(); j++) {
            if (std::tolower(str[i]) == std::tolower(str[j])) {
                return false;
            }
        }
    }
    return true;
}
    На заметку:

    #include <cctype> — библиотека, необходимая для работы с посимвольными функциями, включая приведение регистра букв.
    std::tolower() — функция, которая принимает символ и возвращает его в нижнем (маленьком) регистре. Если символ уже строчный или не является буквой, он остается без изменений.
    Вложенный цикл — внешний цикл фиксирует текущую букву по индексу i, а внутренний цикл с переменной j = i + 1 проверяет только те символы, которые идут строго после неё. Это исключает повторное сравнение одних и тех же пар и сравнение буквы самой с собой.
    return false; — инструкция мгновенного выхода из функции. Как только внутренний if находит первое совпадение букв, выполнение всей функции прекращается, возвращая результат. Внешний код не тратит время на проверку остатка строки.


    Инсайт дня: Область видимости переменных (Variable Scope)

    Переменные, созданные внутри круглых скобок цикла for (size_t i = 0; ...), существуют и «видны» компилятору только внутри тела этого конкретного цикла (между его фигурными скобками { }).

    Почему это важно: Если закрыть фигурные скобки первого цикла, а затем ниже попытаться открыть второй цикл и использовать в нем переменную i (например, j = i + 1), компилятор выдаст ошибку error: ‘i’ was not declared in this scope. Для того чтобы внутренний цикл имел доступ к индексу i, он физически должен находиться внутри фигурных скобок внешнего цикла.

    Вывод: Всегда следите за вложенностью блоков кода: переменные «живут» только внутри тех фигурных скобок, где они были объявлены.

    Best Practices: 

    #include <string>
#include <set>
#include <cctype>

bool is_isogram(const std::string& str) {
    std::set<char> unique_letters;
    for (char c : str) {
        unique_letters.insert(std::tolower(c));
    }
    return unique_letters.size() == str.size();
}
    Использование двойного цикла заставляет компьютер совершать слишком много сравнений на длинных строках. В промышленной разработке и для лучшего решения на CodeWars используют структуру данных std::set (множество). Особенность множества в том, что оно хранит только уникальные значения. Мы перебираем строку быстрым циклом for (char c : str) и складываем буквы в set. Если в слове были повторы, set их просто не добавит. В конце мы сравниваем размер множества с длиной исходной строки: если они равны — дубликатов не было.

    Задача 49: "Exes and Ohs"

    Check to see if a string has the same amount of 'x's and 'o's. The method must return a boolean and be case insensitive. The string can contain any char.

    На русском:

    Напишите функцию, которая проверяет, содержит ли строка одинаковое количество букв 'x' и 'o'. Функция должна возвращать логическое значение (true/false) и игнорировать регистр букв. Строка может содержать любые символы.

    // Пример использования:
XO("ooxx");    // => returns true
XO("xooxx");   // => returns false
XO("ooxXm");   // => returns true (регистр игнорируется)
XO("zpzpzpp"); // => returns true (когда нет ни x, ни o, то 0 == 0)
    Решение: 
    bool XO(const std::string& str) { 
    int x = 0; 
    int o = 0; 
    for (int i = 0; i < str.size(); i++){ 
        if(tolower(str[i]) == 'x') x++; 
        if(tolower(str[i]) == 'o') o++; 
    } 
    if (x == o) return true; 
    return false; 
}
    На заметку:

    int x = 0 и int o = 0 — переменные-счетчики. Они создаются до начала цикла, чтобы сохранять и накапливать количество найденных букв при каждой итерации.
    'x' и 'o' — одиночные символы. В C++ они обязательно записываются в одинарных кавычках. Двойные кавычки используются только для целых строк ("строка").
    str[i] — обращение к конкретному символу строки по его индексу. Переменная i увеличивается на каждом шаге цикла, позволяя проверить всю строку от начала до конца.
    Финал функции — сравнение if (x == o) происходит строго после закрытия фигурной скобки цикла for. Функция возвращает результат только тогда, когда компьютер перебрал абсолютно все символы в строке.


    Инсайт дня: Разница между подсчетом и мгновенным выходом

    Если внутри цикла написать return, то функция мгновенно прекратит свою работу, и цикл дальше не пойдет. Это полезно, когда нужно найти один дубликат (как в задаче с изограммой). Но если нужно узнать общее количество чего-либо, то делать return внутри цикла нельзя. Компьютер должен сначала завершить весь цикл, сосчитать все элементы, и только в самом конце выдать результат.

    Best Practices: 

    #include <string>
#include <algorithm>
#include <cctype>

bool XO(const std::string& str) {
    int x = 0;
    int o = 0;
    for (char c : str) {
        if (std::tolower(c) == 'x') x++;
        if (std::tolower(c) == 'o') o++;
    }
    return x == o;
}
    В более продвинутом варианте используется компактный синтаксис. Запись x++ делает ровно то же самое, что и x = x + 1. Вместо громоздкой конструкции if-else в конце пишется строка return x == o;. Компьютер сам вычислит это равенство: если оно верное, вернется true, если неверное — false. Использование цикла for (char c : str) избавляет от необходимости вручную работать с индексами строки.

    Задача 50: "String Ends With?"

    Check to see if the first argument (string) passed in ends with the 2nd argument (also a string). The method must return a boolean.

    На русском:

    Напишите функцию, которая проверяет, заканчивается ли первая строка (str) второй строкой (ending). Функция должна возвращать логическое значение (true/false).

    // Пример использования:
solution("abc", "bc"); // => returns true
solution("abc", "d");  // => returns false
solution("abcde", ""); // => returns true (пустая строка всегда в конце)
    Решение: 
    #include <string>

bool solution(const std::string& str, const std::string& ending) {
if (str.size() < ending.size()) {
    return false;
}
return str.substr(str.size() - ending.size()) == ending;
}
    На заметку:

    str.size() < ending.size() — обязательная защитная проверка. Если искомая концовка длиннее самой строки, то строка физически не может ей заканчиваться. Без этой проверки программа выдаст ошибку при попытке обрезать строку.
    str.substr() — метод, который «отрезает» и возвращает кусочек (подстроку) из исходной строки str. Ему нужно передать индекс, с которого начнется вырезка.
    str.size() - ending.size() — математическая формула для поиска точки старта. Мы вычитаем длину концовки из полной длины строки, чтобы получить точный индекс, с которого должен начинаться хвост строки.
    Финал функции — оператор == сравнивает вырезанный хвост строки с искомым значением ending и сразу возвращает результат (true, если они совпали, и false, если нет).

    Инсайт дня: Безопасность при работе с памятью и индексами

    В C++ метод str.substr() вызовет критическую ошибку std::out_of_range, если передать в него отрицательный индекс. Именно поэтому предварительная проверка str.size() < ending.size() критически важна. Она гарантирует, что разность длин всегда будет больше или равна нулю, защищая программу от аварийного завершения.

    Best Practices: 

    #include <string>

bool solution(const std::string& str, const std::string& ending) {
if (str.length() < ending.length()) return false;

return str.compare(str.length() - ending.length(), ending.length(), ending) == 0;
}
    В более продвинутом варианте используется метод str.compare(). В отличие от substr(), он не создает новую подстроку в памяти компьютера, а просто сверяет символы по указанным индексам «на месте». Запись расшифровывается так: берем строку str, отступаем с конца длину ending, отсчитываем ровно столько символов, сколько длится ending, и сравниваем с самой строкой ending. Если метод возвращает 0, значит, строки абсолютно идентичны. Это решение работает быстрее и экономит оперативную память.

    Если в C++20 и новее, для этой задачи появился стандартный встроенный метод str.ends_with(ending), который делает весь этот процесс одной короткой командой.
