## Задача 1: "Two Sum"

Write a function that takes an array of numbers (integers for the tests) and a target number. It should find two different items in the array that, when added together, give the target value. The indexes of these items should then be returned in a tuple / list (depending on your language) like so: (index1, index2).

For the purposes of this kata, some tests may have multiple answers; any valid solutions will be accepted.

The input will always be valid (numbers will be an array of length 2 or greater, and all of the items will be numbers; target will always be the sum of two different items from that array).

<small>**Примечание: Хотя в задаче просят "tuple", в C++ для пары значений лучше всего подходит `std::pair`.**</small>

???+ "На русском:" 
    Напишите функцию, которая принимает массив чисел (целых чисел для тестов) и целевое число (`target`). Она должна найти в массиве два разных элемента, которые при сложении дают целевое значение. Индексы этих элементов должны быть возвращены в виде пары (tuple/list) вот так: `(index1, index2)`.

    В рамках этого ката некоторые тесты могут иметь несколько вариантов ответа; любой правильный ответ будет принят.
    
    Входные данные всегда корректны: массив длиной 2 или более, все элементы — числа; `target` всегда является суммой двух разных элементов из этого массива.

```cpp
Примеры данных:

two_sum({1, 2, 3}, 4); // returns {0, 2} or {2, 0}
two_sum({3, 2, 4}, 6); // returns {1, 2} or {2, 1}
```
???+ "Решение:"
    ```cpp
    #include <vector>

    std::pair<std::size_t, std::size_t> two_sum(const std::vector<int>& numbers, int target) {
        for (std::size_t i = 0; i < numbers.size(); ++i) {
            for (std::size_t j = i + 1; j < numbers.size(); ++j) {
                if (numbers[i] + numbers[j] == target) {
                    return {i, j};
                }
            }
        }
        return {0, 0};
    }
    ```

???+ "На заметку:"
    <small>`#include <vector>` — это подключение стандартной библиотеки для работы с динамическими массивами (векторами).  
    Зачем: Без этой строки компилятор не поймет, что такое std::vector, и выдаст ошибку.  
    Почему на Codewars его нет: На Codewars этот заголовок (и другие базовые) часто уже скрыто подключен за кулисами в тестовой среде для удобства, чтобы ты писал только саму функцию.
    В реальном проекте в VS Code его обязательно нужно писать самому в начале файла.</small>

<br>
> <big>Инсайт дня: Индексы vs Размер (Off-by-one error)</big>

**Индекс (Index)** — это смещение (дистанция) от начала. От первого элемента до него самого — 0 шагов. Поэтому первый элемент имеет индекс `0`.  
**Размер (Size)** — это общее количество штук. Если в массиве есть хотя бы один предмет, его размер — `1`.  
<small>В векторе размером `N` последний доступный индекс всегда равен `N - 1`. </small>  

**Пример:**  
    Если `numbers.size() == 5`, то:  
Элементы: `1-й`, `2-й`, `3-й`, `4-й`, `5-й`.  
Индексы: `0`, `1`, `2`, `3`, `4`.  
Попытка обратиться к `numbers[5]` приведет к ошибке, так как индекса `5` не существует.

> **Вывод:** Всегда помнить, что цикл должен идти до `i < size`, а не `i <= size`.

## Задача 2: "Even or Odd"

Create a function that takes an integer as an argument and returns "Even" for even numbers or "Odd" for odd numbers.


???+ "На русском:" 
    Создайте функцию, которая принимает целое число в качестве аргумента и возвращает "Even" (Четное) для четных чисел или "Odd" (Нечетное) для нечетных.

```cpp
Примеры данных:

even_or_odd(2);    // returns "Even"
even_or_odd(7);    // returns "Odd"
even_or_odd(-42);  // returns "Even"
```

???+ "Решение:"
    ```cpp
    #include <string>

    std::string even_or_odd(int number) 
    {
      if (number % 2 == 0) {
        return "Even";
      } else {
        return "Odd";
      }
    }
    ```

???+ "На заметку:"
    <small>`std::string` — это тип возвращаемого значения функции, так как мы возвращаем слова, а не числа.  
    Синтаксис `if/else`: условие всегда пишется в круглых скобках `()`, а блоки кода — в фигурных `{}`. Каждая команда внутри заканчивается точкой с запятой `;`.</small>

<br>
> <big>Инсайт дня: Оператор остатка от деления (%)</big>

**Оператор `%` (modulo)** возвращает то, что осталось после деления одного целого числа на другое.  
Если `число % 2 == 0`, значит оно делится на два нацело — это главный способ определить **четность** в программировании.

**Пример:**  
    Если `number == 7`, то `7 % 2` даст `1`. Результат не 0, значит число **нечетное**.  
    Если `number == 8`, то `8 % 2` даст `0`. Результат 0, значит число **четное**.

> **Вывод:** Любая задача, где нужно проверить кратность одного числа другому, решается через оператор `%`.

## Задача 3: "Convert a Number to a String!"

We need a function that can transform a number (integer) into a string. What ways of achieving this do you know?


???+ "На русском:" 
    Нам нужна функция, которая может преобразовать число (целое число) в строку. Какие способы решения этой задачи вы знаете?

    ```cpp
Примеры данных:

    123  --> "123"
    999  --> "999"
    -100 --> "-100"
    ```

???+ "Решение:"
    ```cpp
    #include <string>

    std::string number_to_string(int num) {
      return std::to_string(num);
    }
    ```

???+ "На заметку:"
    <small>`#include <string>` — необходимо подключить, чтобы использовать функцию `std::to_string()`.  
    `std::to_string()` — принимает числовые типы (int, float, double) и возвращает их строковое представление (`std::string`). Это самый простой и современный способ конвертации в C++.</small>

<br>
> <big>Инсайт дня: Строка vs Число (Типизация)</big>

**Число (`int`)** — это значение, с которым можно проводить математические операции (сложение, умножение).  
**Строка (`string`)** — это набор символов (текст). Даже если в строке написано `"123"`, компьютер воспринимает это как последовательность символов, а не как число.

**Пример:**  
    Если `num = 123`, то `123 + 1` даст результат `124`.  
    Если мы работаем со строкой `"123"`, то попытка прибавить к ней `"1"` приведет к склейке текста — `"1231"`.

> **Вывод:** Всегда следи за типами данных: для расчетов используй `int`, для вывода текста или хранения строковых ID — `string`.

## Задача 4: "Guess the Number Game"

Imagine you are creating a game where the user has to guess the correct number. But there is a limit of how many guesses the user can do.

If the user tries to guess more than the limit, the function should throw an error.
If the user guess is right it should return true.
If the user guess is wrong it should return false and lose a life.
Can you finish the game so all the rules are met?

???+ "На русском:" 
    Представьте, что вы создаете игру, в которой пользователь должен угадать правильное число. Но количество попыток (догадок), которые может сделать пользователь, ограничено.
    Если пользователь пытается угадать больше раз, чем позволяет лимит, функция должна выбросить ошибку.
    Если догадка пользователя верна, функция должна вернуть true.
    Если догадка неверна, функция должна вернуть false и пользователь теряет одну жизнь.
    Можете ли вы дописать игру так, чтобы соблюдались все эти правила?

```cpp
// Пример использования:
Guesser game(10, 2); 
game.guess(10); // возвращает true
game.guess(1);  // возвращает false, осталась 1 жизнь
game.guess(1);  // возвращает false, жизней 0
game.guess(1);  // выбрасывает std::runtime_error
```

???+ "Решение:"
    ```cpp
    #include <stdexcept>

    class Guesser
    {
    public:
        // Конструктор инициализирует начальные значения через список инициализации
        Guesser(int number, int lives)
          : number(number), lives(lives)
        { }

        bool guess(int n)
        {
            // 1. Проверяем наличие жизней ПЕРЕД ходом. 
            // Если их 0 или меньше — бросаем ошибку.
            if (lives <= 0) {
                throw std::runtime_error("Expect error: already dead");
            }

            // 2. Проверяем, угадано ли число (сравниваем n и number)
            if (n == number) {
                return true;
            }

            // 3. Если не угадал — уменьшаем жизни и возвращаем false
            // Сюда код дойдет, только если условия выше не сработали.
            lives--;
            return false;
        }

    private:
        int number, lives; // Память объекта (приватные переменные)
    };
    ```

???+ "На заметку:"
    <small>`#include <stdexcept>` — библиотека для работы со стандартными исключениями (ошибками).  
    `throw std::runtime_error("текст")` — команда, которая мгновенно прерывает работу функции и сообщает о критической ошибке.  
    `lives--` — декремент. Короткий способ написать `lives = lives - 1`.</small>

<br>
> <big>Инсайт дня: Списки инициализации vs Присваивание</big>

В C++ запись `: number(number), lives(lives)` называется **списком инициализации**.  
Она записывает данные в переменные **до** того, как выполнение зайдет в фигурные скобки `{}` конструктора. 

**Почему это важно:**  
1. **Скорость:** Переменные "рождаются" сразу с нужными значениями. Это быстрее, чем сначала создавать их пустыми, а потом заполнять внутри скобок.
2. **Пустые скобки:** Так как данные уже сохранены через двоеточие, в самих скобках `{}` делать ничего не нужно. Но по правилам языка они обязаны быть (как точка в конце предложения).

> **Вывод:** Используй двоеточие для настройки «памяти» класса (инициализации), а тело конструктора оставляй пустым.

## Задача 5: "Reversed Strings"

Complete the solution so that it reverses the string passed into it.


???+ "На русском:" 
    Допишите решение так, чтобы оно переворачивало строку, переданную в него.
```cpp
// Пример использования:
reverseString("world"); // возвращает "dlrow"
reverseString("word");  // возвращает "drow"
```

???+ "Решение:"
    ```cpp
    #include <string>

    std::string reverseString(const std::string &str)
    {
        // 1. Создаем новую пустую строку для хранения результата
        std::string result = "";

        // 2. Запускаем цикл от последнего индекса к первому.
        // str.size() - 1 — это номер последней буквы.
        // i-- — на каждом шаге уменьшаем индекс на 1.
        for (int i = str.size() - 1; i >= 0; i--)
        {
        // 3. Берем букву под индексом i и «приклеиваем» её в конец result
            result = result + str[i]; // или result += str[i];
        }

        // 4. Возвращаем готовую перевернутую строку
        return result;
    }
    ```

???+ "На заметку:"
    <small>`std::string` — тип данных (класс) из стандартной библиотеки для работы с текстом.  
    `[str.size() - 1]` — получение индекса последнего символа (так как отсчет идет от 0).  
    `result += str[i]` — оператор, который добавляет символ в конец строки.  
    `const std::string &str` — передача строки в функцию по ссылке (без копирования) и запрет на её изменение.  
    `int i = str.size() - 1` — сделанно не для удобства счета, а для присвоения определнного индекса к переменной `i`.</small>

<br>
> <big>Инсайт дня: Тип данных vs Имя объекта</big>

В программировании важно различать **тип** и **конкретную переменную**. 

**Почему это важно:**  
`std::string` — это название типа (как слово «Машина»), а `str` — это имя конкретной строки, которую нам дали (как «Твоя машина»). Мы не можем спросить размер у самого понятия «Машина», но можем спросить его у конкретного экземпляра.

> **Вывод:** Всегда вызывай методы (через точку) у имени переменной (`str.size()`), а не у названия типа (`std::string`).

## Задача 6: "Return Negative"

In this simple assignment you are given a number and have to make it negative. But maybe the number is already negative?


???+ "На русском:" 
    В этом задании вам дается число, и его нужно сделать отрицательным. Но что, если число уже отрицательное?
    Если число положительное — сделайте его отрицательным. Если оно уже меньше или равно нулю — оставьте как есть.

```cpp
// Пример использования:
makeNegative(1);  // возвращает -1
makeNegative(-5); // возвращает -5
makeNegative(0);  // возвращает 0
```

???+ "Решение:"
    ```cpp
    int makeNegative(int num)
    {
      // 1. Проверяем, является ли число положительным или нулем.
      if (num >= 0) 
      {
          // 2. Если да, возвращаем его с унарным минусом.
          return -num;
      }
      
      // 3. Если число уже отрицательное, просто возвращаем его без изменений.
      // Благодаря return выше, блок else нам не требуется.
      return num;
    }
    ```

???+ "На заметку:"
    <small>`if` — оператор ветвления. Позволяет выполнять код только при соблюдении условия.  
    `return` — оператор выхода из функции. Как только компьютер встречает его, функция завершается.  
    `Унарный минус (-num)` — математический оператор, который меняет знак числа на противоположный.  
    `Фигурные скобки {}` — обязательны, если в `if` несколько команд. Если команда одна (как в нашем `return`), скобки можно опустить для краткости.</small>

<br>
> <big>Инсайт дня: Early Return (Ранний выход)</big>

В коде выше мы не использовали `else`. Если условие `if` сработало, выполнится первый `return`, и функция сразу «умрет». До второй строки с `return` программа просто не доберется.

**Почему это важно:**  
Это делает код чище и избавляет от лишних вложенных скобок. Такой подход часто называют «стилем охранника» (Guard Clause): мы сначала проверяем частный случай, а потом спокойно пишем основной код.

> **Вывод:** Если в блоке `if` есть `return`, писать `else` после него не обязательно.

## Задача 7: "Convert boolean values to strings 'Yes' or 'No'"

Complete the method that takes a boolean value and return a "Yes" string for true, or a "No" string for false.

???+ "На русском:" 
    Напишите функцию, которая принимает логическое значение (bool) и возвращает строку "Yes", если значение — true, или "No", если значение — false.

```cpp
// Пример использования:
bool_to_word(true);  // возвращает "Yes"
bool_to_word(false); // возвращает "No"
```

???+ "Решение:"
    ```cpp
    #include <string>

    std::string bool_to_word(bool value)
    {
      // 1. Проверяем логическое значение value.
      // Короткая запись if (value) заменяет if (value == true).
      if (value) 
      {
          return "Yes";
      }
      
      // 2. Если значение false — возвращаем "No".
      // Текст обязательно оборачиваем в двойные кавычки.
      return "No";
    }
    ```

???+ "На заметку:"
    <small>`bool` — логический тип данных (`true` или `false`).  
    `"Строка"` — в C++ текстовые строки всегда пишутся в двойных кавычках. Одинарные кавычки `'a'` используются только для одного символа (`char`).  
    `if (value)` — автоматическая проверка на истинность. Если в скобках `true`, код внутри сработает.</small>

<br>
> <big>Инсайт дня: Краткость логических проверок</big>

В C++ конструкцию `if (value == true)` принято сокращать до **`if (value)`**. 

**Почему это важно:**  
Оператор `if` по определению ждет логическое значение. Проверка «равно ли истина истине» — лишнее действие. Это делает код чище и профессиональнее.

> **Вывод:** Пиши `if (value)`, если проверяешь на правду, и `if (!value)`, если проверяешь на ложь.

## Задача 8: "Opposite number"

Very simple, given a number, find its opposite (additive inverse).

???+ "На русском:" 
    Очень простая задача: дано число, найдите противоположное ему (аддитивную инверсию).

```cpp
// Пример использования:
opposite(1);    // возвращает -1
opposite(-14);  // возвращает 14
```

???+ "Решение:"
    ```cpp
    int opposite(int number) 
    {
      // Используем унарный минус, чтобы инвертировать знак.
      // Не забудь поставить точку с запятой в конце!
      return -number; 
    }
    ```

???+ "На заметку:"
    <small>**Унарный минус** — это оператор `-`, который применяется к одному операнду. Он меняет знак числа на противоположный (плюс на минус, минус на плюс).  
    **Точка с запятой `;`** — в C++ это обязательный символ в конце каждого выражения (инструкции). Без неё код не скомпилируется.</small>

<br>
> <big>Инсайт дня: Минус на минус дает плюс</big>

В программировании работают те же правила математики. Тебе не нужно писать `if`, чтобы проверять, положительное число или отрицательное. Унарный минус сам превратит `-34` в `34`.

**Почему это важно:**  
Это самый лаконичный способ изменить знак. Тебе не нужны сложные функции — просто один символ перед именем переменной.

> **Вывод:** Для поиска противоположного числа всегда используй `-number`. И всегда проверяй наличие `;` в конце строки `return`.

## Задача 9: "Vowel Count"

Return the number (count) of vowels in the given string. We will consider a, e, i, o, u as vowels for this Kata (but not y).

???+ "На русском:" 
    Верните количество гласных в заданной строке. Мы будем считать a, e, i, o, u гласными для этого ката (но не y). Входная строка будет состоять только из строчных букв и/или пробелов.

```cpp
// Пример использования:
getCount("abracadabra"); // возвращает 5
getCount("celebration"); // возвращает 5
```

???+ "Решение:"
    ```cpp
    #include <string>

    using namespace std;

    int getCount(const string& inputStr) {
      int num_vowels = 0;
      
      // Используем цикл for для перебора индексов строки
      for (int i = 0; i < inputStr.size(); i++) 
      {
        // Проверяем символ по индексу i на совпадение с гласными
        if (inputStr[i] == 'a' || inputStr[i] == 'e' || inputStr[i] == 'i' || inputStr[i] == 'o' || inputStr[i] == 'u') 
        {
          num_vowels++; 
        }
      }
      
      return num_vowels;
    }
    ```

???+ "На заметку:"

```cpp
// Пример использования:
```

> <big>Инсайт дня: Цикл — это последовательная работа</big>

**Почему это важно:**

В этой задаче связь между `count_sheep(vector<bool> arr)` и `arr[i]` является ключевой. Переменная `arr` — это мост, по которому данные попадают внутрь вашего алгоритма. Вы не просто пишете код «в пустоте», вы описываете действия над конкретным объектом, который придет в функцию в момент запуска.

## Задача 26: "Opposites Attract"

    ```cpp
    }
    ```

???+ "На заметку:"
    <small>**`f1 % 2 == 0`** — проверка на четность. Если остаток от деления на 2 равен нулю, число четное.  
    **`&&` (Логическое И)** — связывает условия. Часть выражения будет верна только если оба условия по бокам от `&&` выполнены одновременно.  
    **`||` (Логическое ИЛИ)** — позволяет проверить несколько сценариев. Нам подходит либо вариант "четный-нечетный", либо "нечетный-четный".  
    **Приоритет операторов** — в C++ оператор `&&` выполняется раньше, чем `||`, поэтому твоя логика работает правильно даже без дополнительных внутренних скобок.</small>

<br>
> <big>Инсайт дня: Логические связки строят сложные правила</big>

В этой задаче ты объединил несколько простых проверок в одну мощную логическую цепь. Это именно то, чем занимаются разработчики на удаленке: переводят сложные бизнес-правила (вроде условий влюбленности или правил выдачи кредита) на язык логических операторов.

**Почему это важно:**  
Умение комбинировать `&&` и `||` позволяет тебе описывать любые условия в одну строку. Это делает код компактным, а твой навык чтения таких выражений приближает тебя к уровню миддла, который видит структуру логики с первого взгляда.

> **Вывод:** Код `if (f1 % 2 == 0 && ...)` — это наглядный пример того, как программа принимает решение, основываясь на сочетании нескольких факторов.

## Задача 27: "Convert number to reversed array of digits"

Given a random non-negative number, you have to return the digits of this number within an array in reverse order.

???+ "На русском:" 
    Дано целое положительное число. Вам нужно вернуть массив, состоящий из цифр этого числа в обратном порядке. Например, из 35231 должно получиться [1, 3, 2, 5, 3].

```cpp
// Пример использования:
digitize(35231); // возвращает [1, 3, 2, 5, 3]
digitize(0);     // возвращает [0]
```

???+ "Решение:"
    ```cpp
    std::vector<int> digitize(unsigned long n) 
    {  
      std::vector<int> result;
      // Если на вход пришел ноль, сразу отдаем массив с нулем
      if (n == 0) return {0}; 
      
      while (n > 0){
        // Отщипываем последнюю цифру и кладем в вектор
        result.push_back(n % 10);
        // Убираем эту цифру из самого числа
        n = n / 10;
      }
      return result;  
    }
    ```

???+ "На заметку:"
    <small>**`std::vector<int>`** — динамический массив, который сам расширяется, когда мы добавляем в него элементы.  
    **`while (n > 0)`** — идеальный цикл, когда мы не знаем, сколько цифр в числе. Он работает, пока от числа что-то остается.  
    **`result.push_back(n % 10)`** — «толкает» последнюю цифру (остаток от деления на 10) в конец нашего списка.  
    **`n = n / 10`** — отрезает последнюю цифру от числа, чтобы на следующем круге достать новую.  
    **Фигурные скобки `{0}`** — используются для мгновенного создания (инициализации) вектора с готовыми данными. Мы не используем здесь квадратные скобки `[]`, так как они нужны для обращения к уже существующим элементам по индексу, а `{}` — для создания новых.</small>

<br>
> <big>Инсайт дня: Число — это набор разрядов</big>

В этой задаче ты научился «разбирать» число на части, используя только математику. Вместо того чтобы превращать всё в текст (строки), ты работаешь напрямую с разрядами числа через `%` и `/`.

**Почему это важно:**  
Это самый быстрый и эффективный способ работы с числами в C++. Для будущего миддла понимание того, как «откусывать» куски данных через остаток от деления — это база, которая пригодится и в алгоритмах, и в работе с памятью.

> **Вывод:** Комбинация `while`, `%` и `push_back` — это классический прием для трансформации данных, который работает безотказно.

???+ "Best Practices:"
    ```cpp
     do {
        digits.push_back (n % 10);
        n /= 10;
    } while (n > 0);
    ```
    `do...while`: Это правильный выбор, так как цикл выполнится хотя бы один раз. Если `n` = `0`, программа корректно запишет цифру `0` в список. Обычный `while` в таком случае просто бы не запустился.

## Задача 28: "Beginner - Lost Without a Map"

Given an array of integers, return a new array with each value doubled.

???+ "На русском:" 
    Дан массив целых чисел. Вам нужно вернуть новый массив, в котором каждое значение из исходного будет удвоено. Например, из `` должно получиться ``.

```cpp
// Пример использования:
maps({1, 2, 3}); // возвращает
maps({4, 1, 1}); // возвращает
```

???+ "Решение:"
    ```cpp
    std::vector<int> maps(const std::vector<int> & values) {
      std::vector<int> result(values.size());
      
      for (int i = 0; i < values.size(); i++) {
        result[i] = values[i] * 2;
      }
      return result;
    }
    ```

???+ "На заметку:"
    <small>**`std::vector<int> result(values.size())`** — создание вектора с заранее заданным размером. Это самый эффективный способ, так как память выделяется один раз под все элементы сразу.  
    **`result[i] = values[i] * 2`** — прямая запись в ячейку по индексу. Мы берем значение из одной "коробки", удваиваем его и кладем в соответствующую "коробку" в новом векторе.  
    **`for (int i = 0; i < values.size(); i++)`** — классический цикл со счетчиком. Идеально подходит, когда нужно работать с индексами двух разных массивов одновременно.  
    **`const std::vector<int> & values`** — использование ссылки на константу позволяет избежать дорогостоящего копирования данных при передаче в функцию.</small>

<br>
> <big>Инсайт дня: Прямой доступ к памяти — это скорость</big>

В этой задаче ты применил один из самых производительных подходов. Вместо того чтобы заставлять вектор постоянно "расти", ты сразу подготовил место нужного размера.

**Почему это важно:**  
Для C++ крайне важно понимать разницу между динамическим расширением и прямой работой по индексам. Твой вариант минимизирует нагрузку на процессор и память, что критично в реальных высоконагруженных системах.

> **Вывод:** Предварительное выделение памяти через конструктор `result(values.size())` и заполнение через `[i]` — это база производительного программирования.

???+ "Best Practices:"
    ```cpp
    std::vector<int> maps(const std::vector<int> & values) {
      std::vector<int> result;
      for(auto a : values)
      {
        result.push_back(a * 2);
      }
    
      return result;
    }
    ```
    Использование `range-based for` — это современный стандарт читаемости. Код становится лаконичным, избавляя от лишних переменных-счетчиков и делая намерение программиста максимально ясным.

## Задача 29: "MakeUpperCase"

Write a function which converts the input string to uppercase.

???+ "На русском:" 
    Напишите функцию, которая преобразует входную строку в верхний регистр (делает все буквы заглавными).

```cpp
// Пример использования:
makeUpperCase("hello"); // возвращает "HELLO"
makeUpperCase("C++ is cool"); // возвращает "C++ IS COOL"
```

???+ "Решение:"
    ```cpp
    #include <string>
    #include <cctype>

    std::string makeUpperCase(const std::string& str) {
      std::string result = str; // Создаем копию для работы
      
      for (char &c : result) {
        // Берем букву по ссылке (&) и перезаписываем её заглавной
        c = std::toupper(c);
      }
      
      return result;
    }
    ```

???+ "На заметку:"
    <small>**`std::string result = str`** — создание копии. Мы не можем менять оригинал напрямую, так как он защищен словом `const`, поэтому работаем с копией.  
    **`for (char &c : result)`** — цикл по диапазону. Символ `&` (ссылка) критически важен: он дает доступ к букве прямо в памяти строки. Без него мы бы меняли копию буквы, а строка осталась бы прежней.  
    **`c = std::toupper(c)`** — здесь происходит магия. Мы передаем букву в функцию, она возвращает заглавную версию, и через `=` мы кладем её обратно на то же место.  
    **`c`** — это просто традиционное имя переменной (сокращение от character). Можно заменить на любое слово, лишь бы оно совпадало в обеих частях строки.</small>

<br>
> <big>Инсайт дня: Порядок действий имеет значение</big>

В строке `c = std::toupper(c)` компьютер сначала вычисляет то, что справа (делает букву большой), а только потом записывает результат в то, что слева.

**Почему это важно:**  
Знак `=` в программировании — это не равенство, а команда «присвоить». Сначала мы готовим «товар» (справа), а потом кладем его в «коробку» (слева). Понимание этого порядка — ключ к чтению любого кода.

> **Вывод:** Ссылка `&` позволяет редактировать данные внутри контейнера, а функция `toupper` — самый простой способ смены регистра для базовых символов.

???+ "Best Practices:"
    ```cpp
    #include <string>
    #include <algorithm>
    #include <cctype>

    std::string makeUpperCase(std::string str) {
      // Используем стандартный алгоритм для прохода по всей строке
      std::transform(str.begin(), str.end(), str.begin(), 
                     [](unsigned char c) { return std::toupper(c); });
      return str;
    }
    ```
    Использование `std::transform` из библиотеки `<algorithm>` считается более «взрослым» способом. Это избавляет от написания циклов вручную и сводит задачу к одной строчке кода.

## Задача 30: "Paperwork"

Your classmates asked you to copy some paperwork for them. You know that there are 'n' classmates and the paperwork has 'm' pages. Your task is to calculate how many blank pages do you need. If n < 0 or m < 0 return 0.

???+ "На русском:" 
    Ваши одноклассники попросили вас размножить для них документы. Вы знаете, что есть `n` одноклассников и в документе `m` страниц. Ваша задача — вычислить, сколько чистых листов вам понадобится. Если `n < 0` или `m < 0`, верните `0`.

```cpp
// Пример использования:
paperwork(5, 5);   // возвращает 25
paperwork(-5, 5);  // возвращает 0
paperwork(5, 0);   // возвращает 0
```

???+ "Решение:"
    ```cpp
    int paperwork(int n, int m) {
      if (n < 0 || m < 0) {
        return 0;
      }
      return n * m;
    }
    ```

???+ "На заметку:"
    <small>**`if (n < 0 || m < 0)`** — проверка входных данных. Оператор `||` означает «ИЛИ». Если хотя бы одно из чисел отрицательное, условие срабатывает.  
    **`return 0`** — мгновенный выход из функции. Если условие выше выполнилось, программа отдает ноль и не идет дальше к умножению.  
    **`return n * m`** — базовая математика. Если числа положительные, мы просто их перемножаем.  
    **`int`** — целочисленный тип данных. Так как мы считаем людей и страницы, нам не нужны дробные числа.</small>

<br>
> <big>Инсайт дня: Математика экономит строки кода</big>

В этой задаче важно было заметить, что случай с нулем (`n=0` или `m=0`) не требует отдельной проверки в `if`.

**Почему это важно:**  
Любое число, умноженное на ноль, дает ноль. Твой код написан чисто, потому что ты доверил математике обработку нулей, сосредоточившись в `if` только на ошибочных (отрицательных) значениях. Это делает программу быстрее и понятнее.

> **Вывод:** Всегда старайся разделять «ошибочные данные» (которые нужно пресечь через `if`) и «корректные данные» (которые может обработать основная логика).

???+ "Best Practices:"
    ```cpp
    int paperwork(int n, int m) {
      // Использование тернарного оператора для краткости
      return (n < 0 || m < 0) ? 0 : n * m;
    }
    ```
    В C++ часто используют тернарный оператор `(условие) ? результат1 : результат2`. Это просто короткая запись твоего `if-else`. Но твой текущий вариант через обычный `if` читается гораздо легче, когда ты только учишься.

## Задача 31: "Simple multiplication"

This kata is about multiplying a given number by eight if it is an even number and by nine otherwise.

???+ "На русском:" 
    В этой задаче нужно умножить заданное число на восемь, если оно четное, и на девять, если оно нечетное.

```cpp
// Пример использования:
simpleMultiplication(2); // возвращает 16 (четное: 2 * 8)
simpleMultiplication(3); // возвращает 27 (нечетное: 3 * 9)
```

???+ "Решение:"
    ```cpp
    int simpleMultiplication(int a) {
      return (a % 2 == 0) ? a * 8 : a * 9;
    }
    ```

???+ "На заметку:"
    <small>**`a % 2 == 0`** — классическая проверка на четность. Оператор `%` (остаток от деления) возвращает 0, если число делится на 2 без остатка.  
    **`? :`** — тернарный оператор. Это компактная замена `if-else`. Если условие слева от `?` верно, выполняется код после `?`, если нет — после `:`.  
    **`a * 8` и `a * 9`** — арифметика, которая срабатывает в зависимости от результата проверки.  
    **`return`** — сразу возвращает результат вычисления всей этой конструкции.</small>

<br>
> <big>Инсайт дня: Краткость — сестра C++</big>

Тернарный оператор идеально подходит для таких простых условий "или-или". Он делает код очень компактным, превращая функцию в одну понятную строку.

**Почему это важно:**  
В реальной разработке простые функции часто пишут именно так. Это экономит место на экране и позволяет быстрее читать код. Главное — не переборщить: если условий станет больше (например, проверка на три разных числа), лучше вернуться к обычному `if-else`.

> **Вывод:** Ты применил профессиональный подход. Использование `? :` вместо полноценного `if-else` там, где это уместно, — признак того, что ты начинаешь чувствовать стиль языка.

???+ "Best Practices:"
    ```cpp
    int simpleMultiplication(int a) {
    ```

    Этот вариант — пик лаконичности. Здесь мы используем тот факт, что для нечетных чисел `a % 2` вернет `1` (истина), что сразу активирует первую ветку тернарного оператора.

## Задача 33: "Abbreviate a Two Word Name"

Write a function to convert a name into initials. This kata strictly takes two words with one space in between them. The output should be two capital letters with a dot separating them.

???+ "На русском:" 
    Напишите функцию, которая преобразует имя в инициалы. На вход всегда подаются два слова с одним пробелом между ними. Результат должен состоять из двух заглавных букв, разделенных точкой.

```cpp
// Пример использования:
abbrevName("Sam Harris");     // возвращает "S.H"
abbrevName("patrick feeney"); // возвращает "P.F"
```

???+ "Решение:"
    ```cpp
    #include <string>
    #include <cctype>

    std::string abbrevName(std::string name) {
      std::string result = "";
      
      // 1. Берем первый символ и принудительно превращаем результат toupper в char
      result = result + (char)std::toupper(name[0]);
      
      // 2. Добавляем точку
      result += '.';
      
      // 3. Ищем пробел и берем символ после него
      for (int i = 0; i < name.size(); i++) {
        if (name[i] == ' ') {
          result += (char)std::toupper(name[i + 1]);
        }
      }
      
      return result;
    }
    ```

???+ "На заметку:"
    <small>**`(char)std::toupper`** — явное приведение типа. Функция `toupper` возвращает числовой код буквы (`int`), а чтобы "склеить" его со строкой, нам нужно превратить этот код обратно в символ (`char`).  
    **`name[0]`** — первая буква имени.  
    **`if (name[i] == ' ')`** — находим место, где заканчивается имя и начинается фамилия.  
    **`name[i + 1]`** — берем символ, стоящий сразу за пробелом (первую букву фамилии).</small>

<br>
> <big>Инсайт дня: Строгая типизация требует точности</big>

В C++ нельзя просто так сложить строку и число. Ошибка `invalid operands` возникла потому, что компьютер видел попытку прибавить код буквы (например, 65) к тексту.

**Почему это важно:**  
Это учит тебя всегда следить за тем, что именно ты складываешь. Если функция возвращает `int`, а тебе нужна буква — используй `(char)`. Это "переводчик", который заставляет разные типы данных работать вместе.

> **Вывод:** Приведение типов `(char)` и работа с индексами `[i+1]` — это ключевые навыки для манипуляции текстом в C++.

???+ "Best Practices (через find):"

    ```cpp
    #include <string>

    std::string abbrevName(std::string name) {
    ```

## Задача 34: "A Needle in the Haystack"

Can you find the needle in the haystack? Write a function `findNeedle()` that takes an array full of junk but containing one "needle". After your function finds the needle it should return a message (as a string) that says: "found the needle at position " plus the index it found the needle.

???+ "На русском:" 
    Напишите функцию, которая находит «иголку» в «стоге сена». На вход подается вектор, заполненный строками-пустышками, но где-то среди них есть одна строка `"needle"`. Функция должна вернуть фразу с указанием индекса (номера ячейки), где была найдена иголка.

```cpp
// Пример использования:
findNeedle({"hay", "junk", "needle"}); // возвращает "found the needle at position 2"
```

???+ "Решение:"
    ```cpp
    #include <vector>
    #include <string>

    std::string findNeedle(const std::vector<std::string>& haystack)
    {
      // 1. Используем цикл для перебора всех элементов вектора
      // Используем size_t, так как это стандартный тип для индексов и размеров
      for (size_t i = 0; i < haystack.size(); i++) {
        
        // 2. Сравниваем текущую строку в векторе с искомым словом
        if (haystack[i] == "needle") {
          
          // 3. Формируем строку: текст + число, преобразованное в строку
          return "found the needle at position " + std::to_string(i);
        }
      }
      return ""; // Формальный возврат, если иголка не найдена
    }
    ```

???+ "На заметку:"
    <small>**`std::vector<std::string>`** — это динамический массив строк. Индекс `[i]` здесь указывает на конкретное слово целиком, а не на отдельную букву.  
    **`size_t`** — беззнаковый целочисленный тип. Его использование вместо `int` для счетчика цикла — признак хорошего тона в C++, так как он всегда соответствует размеру памяти системы.  
    **`std::to_string(i)`** — критически важная функция. Она берет число (индекс) и создает его текстовую копию. Без этого шага сложить текст и число через `+` не получится.  
    **`return` внутри цикла** — как только иголка найдена, `return` мгновенно завершает выполнение всей функции и выдает результат.</small>

<br>
> <big>Инсайт дня: Тип контейнера определяет логику поиска</big>

В C++ работа с `std::vector<std::string>` отличается от работы с обычной строкой `std::string`. В векторе один индекс — это один объект (в данном случае целое слово).

**Почему это важно:**  
Это избавляет от необходимости перебирать каждую букву вручную. Понимание того, что именно хранится в «ячейке» контейнера, позволяет писать код быстрее и избегать лишних вложенных циклов.

> **Вывод:** Правильный выбор типа счетчика (`size_t`) и своевременное приведение типов (`to_string`) — залог стабильного кода в C++.

???+ "Best Practices (через итераторы):"
    ```cpp
    #include <vector>
    #include <string>
    #include <algorithm> // Для std::find

    std::string findNeedle(const std::vector<std::string>& haystack) {
      // Находим итератор (указатель) на нужный элемент
      auto it = std::find(haystack.begin(), haystack.end(), "needle");
      
      // Вычисляем расстояние от начала до найденного элемента (индекс)
      auto index = std::distance(haystack.begin(), it);
      
      return "found the needle at position " + std::to_string(index);
    }
    ```
    Использование STL-алгоритмов (`std::find`) считается более идиоматичным подходом в современном C++, так как уменьшает вероятность ошибки в условиях цикла.

## Задача 35: "Multiples of 3 or 5"

If we list all the natural numbers below 10 that are multiples of 3 or 5, we get 3, 5, 6 and 9. The sum of these multiples is 23. Finish the solution so that it returns the sum of all the multiples of 3 or 5 below the number passed in. Additionally, if the number is negative, return 0.

???+ "На русском:" 
    Нужно найти сумму всех чисел, которые строго меньше заданного `number` и делятся на 3 или на 5. Если число отрицательное — возвращаем 0. Если число кратно и 3, и 5 одновременно (например, 15), оно учитывается в сумме только один раз.

```cpp
// Пример использования:
solution(10); // возвращает 23 (3 + 5 + 6 + 9)
```

???+ "Решение:"
    ```cpp
    int solution(int number) 
    {
      int result = 0;
      
      // 1. Проходим циклом по всем числам от 0 до number (не включая его)
      for (int i = 0; i < number; i++) {
        
        // 2. Проверяем текущее число i на кратность через остаток от деления (%)
        // Если i делится на 3 ИЛИ на 5 без остатка
        if (i % 3 == 0 || i % 5 == 0) {
          
          // 3. Плюсуем само число i к итоговой сумме
          result += i;
        }
      }
      
      // 4. Возвращаем результат. Если number <= 0, цикл не запустится и вернется 0.
      return result;
    }
    ```

???+ "На заметку:"
    <small>**`i % 3 == 0`** — проверка на кратность: если остаток от деления на 3 равен нулю, число нам подходит.  
    **`||` (логическое ИЛИ)** — условие выполняется, если число делится хотя бы на одно из указанных чисел (3 или 5).  
    **`i < number`** — строгое сравнение, так как по условию нужны числа "below" (ниже) заданного.  
    **`result += i`** — мы суммируем значения самих подходящих чисел, а не их количество.</small>

<br>
> <big>Инсайт дня: Счётчик цикла — это и есть твои данные</big>

В отличие от задач с массивами, где счётчик `i` — это лишь «ключ» от ящика, здесь `i` — это само число, которое мы проверяем и складываем. 

**Почему это важно:**  
Это учит различать «бегунок» (`i`) и статичную «границу» (`number`). Проверка `number % 3` внутри цикла была бы ошибкой, так как лимит не меняется, а проверять нужно каждое число по пути.

> **Вывод:** Оператор остатка от деления (`%`) — базовый инструмент для любых задач на фильтрацию числовых последовательностей.

???+ "Best Practices (Clean Code):"
    ```cpp
    int solution(int number) 
    {
      int sum = 0;
      // Начинаем с 3, так как 0, 1 и 2 гарантированно не делятся на 3 или 5.
      // Используем n как сокращение от number для наглядности.
      for (int n = 3; n < number; n++) {
        // Явные скобки помогают быстрее читать логику условия
        if ((n % 3 == 0) || (n % 5 == 0)) {
          sum += n;
        }
      }
      return sum;
    }
    ```
    Это решение считается лучшим, так как оно оптимизирует старт цикла (пропуская заведомо неподходящие 0, 1, 2) и использует максимально прозрачную структуру условий.

## Задача 36: "Split Strings"

Complete the solution so that it splits the string into strings of two characters in a list/array. If the string contains an odd number of characters then it should replace the missing second character of the final pair with an underscore ('_').

???+ "На русском:" 
    Напишите функцию, которая разбивает строку на пары из двух символов и возвращает их в виде вектора. Если в строке нечетное количество символов, то последний символ в паре должен быть дополнен нижним подчеркиванием ('_').

```cpp
// Пример использования:
solution("abc");    // возвращает {"ab", "c_"}
solution("abcdef"); // возвращает {"ab", "cd", "ef"}
```

???+ "Решение:"
    ```cpp
    #include <string>
    #include <vector>

    std::vector<std::string> solution(const std::string &s)
    {
      std::vector<std::string> result;

      // 1. Проходим циклом по строке с шагом 2
      for (int i = 0; i < s.size(); i += 2) {
        
        // 2. Создаем временную строку для текущей пары
        std::string pair = "";
        pair += s[i];

        // 3. Если есть следующий символ — добавляем его, иначе — добавляем '_'
        if (i + 1 < s.size()) {
          pair += s[i + 1];
        } else {
          pair += '_';
        }

        // 4. Добавляем готовую пару в результирующий вектор
        result.push_back(pair);
      }

      return result;
    }
    ```

???+ "На заметку:"
    <small>**`i += 2`** — позволяет сразу переходить к началу следующей пары, не обрабатывая каждый символ отдельно.  
    **`s.size()`** — используется для проверки границ строки, чтобы избежать выхода за пределы массива при обращении к `s[i + 1]`.  
    **`pair += '_'`** — это условие срабатывает только один раз в самом конце, если общее количество символов было нечетным.  
    **`result.push_back(pair)`** — помещает сформированную строку из двух символов в конец нашего списка ответов.</small>

<br>
> <big>Инсайт дня: Шаг цикла определяет структуру</big>

Когда нужно сгруппировать данные (например, по 2, 3 или 10 элементов), проще всего управлять этим через **шаг итерации** в цикле `for`. 

**Почему это важно:**  
Вместо того чтобы внутри цикла писать сложную логику «накопления» символов, мы заранее говорим программе: «прыгай через один». Это делает код предсказуемым: внутри цикла мы всегда работаем только с текущим окном данных.

> **Вывод:** Алгоритм «Цикл с кастомным шагом + проверка соседа» — самый надежный способ сегментации любых последовательностей.

???+ "Best Practices (через substr):"
    ```cpp
    #include <string>
    #include <vector>

    std::vector<std::string> solution(const std::string &s) {
      std::vector<std::string> res;
      for (int i = 0; i < s.length(); i += 2) {
        // Вырезаем 2 символа. Если символ один, substr возьмет только его.
        std::string part = s.substr(i, 2);
        
        // Если длина куска меньше 2, дополняем подчеркиванием
        if (part.length() < 2) part += '_';
        
        res.push_back(part);
      }
      return res;
    }
    ```
    Метод `substr` делает код более читаемым («вырезать подстроку»), избавляя от ручного сложения отдельных символов через оператор `+=`.

## Задача 37: "Disemvowel Trolls"

Trolls are attacking your comment section! A common way to deal with this situation is to remove all of the vowels from the trolls' comments, neutralizing the threat. Your task is to write a function that takes a string and return a new string with all vowels removed.

???+ "На русском:" 
    Тролли атакуют ваши комментарии! Распространенный способ справиться с этой ситуацией — удалить все гласные из комментариев троллей, нейтрализуя угрозу. Ваша задача — написать функцию, которая принимает строку и возвращает новую строку, в которой удалены все гласные. (Для справки: в английском языке буква "y" не считается гласной в этой задаче).

```cpp
// Пример использования:
disemvowel("This website is for losers LOL!"); // возвращает "Ths wbst s fr lsrs LL!"
```

???+ "Решение:"
    ```cpp
    #include <string>

    std::string disemvowel(const std::string& str) {
      std::string result = "";
      std::string vowels = "aeiouAEIOU";

      for (char c : str) {
        if (vowels.find(c) == std::string::npos) {
          result += c;
        }
      }
        
      return result;
    }
    ```

???+ "На заметку:"
    <small>**`std::string::npos`** — возвращается методом `find`, если символ не найден.  
    **`for (char c : str)`** — итерируется по каждому символу строки.  
    **`vowels.find(c)`** — проверяет наличие текущего символа в списке «запрещенных».  
    **Регистр (A/a)** — поиск чувствителен к регистру, поэтому в строке `vowels` указаны оба варианта.</small>

<br>
> <big>Инсайт дня: Инструмент под задачу</big>

Использование **RegEx** (регулярных выражений) превращает код в декларативное описание: мы не пишем алгоритм удаления, мы описываем «что именно» должно исчезнуть.

**Почему это важно:**  
Это сокращает количество строк и делает код легко масштабируемым. Если условия задачи изменятся (например, нужно будет удалять еще и цифры), вам достаточно будет изменить только строку шаблона, не трогая логику программы.

> **Вывод:** Регулярные выражения — самый мощный инструмент для сложной обработки текста, хотя они и чуть медленнее обычных циклов.

???+ "Best Practices:"
    ```cpp
    #include <string>
    #include <regex>

    std::string disemvowel(std::string str) {
      // 1. Создаем регулярное выражение, описывающее все гласные
      std::regex vowels("[aeiouAEIOU]");
      
      // 2. Заменяем все совпадения на пустую строку ""
      return std::regex_replace(str, vowels, "");
    }
    ```
    Метод `std::regex_replace` — это "золотой стандарт" для задач на замену или удаление подстрок по шаблону. Он избавляет от необходимости писать ручные циклы и проверки, делая код максимально чистым и понятным.

## Задача 39: "Create Phone Number"

Write a function that accepts an array of 10 integers (between 0 and 9), that returns a string of those numbers in the form of a phone number.

???+ "На русском:" 
    Напишите функцию, которая принимает массив из 10 целых чисел (от 0 до 9) и возвращает строку в формате телефонного номера: `(123) 456-7890`.

```cpp
// Пример использования:
createPhoneNumber(int{1, 2, 3, 4, 5, 6, 7, 8, 9, 0}) // => returns "(123) 456-7890"
```

???+ "Решение:"
    ```cpp
    #include <string>
    #include <cstdio>

    std::string createPhoneNumber(const int arr[10]) {
      char buf[15];
      snprintf(buf, sizeof(buf), "(%d%d%d) %d%d%d-%d%d%d%d", 
               arr[0], arr[1], arr[2], arr[3], arr[4], 
               arr[5], arr[6], arr[7], arr[8], arr[9]);
      return buf;
    }
    ```

???+ "На заметку:"
    <small>**`char buf[15]`** — выделение фиксированной памяти под 14 символов и нулевой терминатор.  
    **`snprintf`** (**s**tring **n**umber **f**ormatted) — записывает данные в буфер по шаблону, ограничивая длину (`n`) для безопасности.    
    **`sizeof(buf)`** — ограничитель, гарантирующий, что запись не выйдет за границы массива.  
    **`%d`** — спецификатор для подстановки целых чисел.</small>

<br>
> <big>Инсайт дня: Эффективность шаблонов</big>

Использование низкоуровневых функций форматирования позволяет избежать создания множества временных строковых объектов, что критически важно для производительности в C++.

**Почему это важно:**  
На собеседованиях знание функций семейства `printf` и понимание устройства `char` массивов показывает, что вы понимаете, как программа работает с памятью «под капотом».

> **Вывод:** Для строго фиксированных форматов данных `snprintf` — самый эффективный и наглядный инструмент.

    ```cpp
    #include <string>

    std::string createPhoneNumber(const int arr[10]) {
    ```

## Задача 40: "Square Every Digit"

Welcome. In this kata, you are asked to square every digit of a number and concatenate them. For example, if we run 9119 through the function, 811181 will come out, because 9² is 81 and 1² is 1.

???+ "На русском:" 
    Напишите функцию, которая возводит каждую цифру числа в квадрат и склеивает их в один результат. Функция принимает целое число и возвращает целое число.

```cpp
// Пример использования:
square_digits(9119) // => returns 811181
square_digits(765)  //  returns 493625
```

???+ "Решение:"
    ```cpp
    #include <string>

    using namespace std;

    int square_digits(int num) {
        // Переводим число в строку (например, 765 -> "765")
        string s = to_string(num);
        string result = "";
        
        // Перебираем символы по индексам слева направо
        for (int i = 0; i < s.length(); i++) {
            char bukva = s[i];
            
            // Трюк: переводим символ в цифру через вычитание кода нуля ('0' = 48)
            int digit = bukva - '0';
            
            // Возводим в квадрат и приклеиваем обратно как текст
            result += to_string(digit * digit);
        }
        
        // Превращаем итоговую строку текста обратно в целое число
        return stoi(result);
    }
    ```

???+ "На заметку:"
    <small>**`to_string`** — превращает любое число в строку текста для посимвольной работы.  
    **`bukva - '0'`** — костыль C++. Компьютер видит символ `'7'` как код 55, а `'0'` как код 48. Вычитая их ($55 - 48$), получаем чистую цифру `7`.  
    **`result +=`** — склеивает текст. Для строк операция `"49" + "36"` дает `"4936"`, а не складывает их математически.  
    **`stoi`** (**s**tring **to** **i**nteger) — парсит готовую строку цифр обратно в тип `int`.</small>

<br>
> <big>Инсайт дня: Строковая логика vs Математика</big>

Перевод числа в строку избавляет от необходимости высчитывать математические разряды и делители. Строка позволяет двигаться по числу так же, как человек читает книгу — строго слева направо по индексам.

**Почему это важно:**  
В промышленной разработке читаемость кода часто важнее микрооптимизаций. Вариант со строками пишется за 30 секунд, его легко читать и в нем практически невозможно ошибиться с разрядами чисел.

> **Вывод:** Если нужно разобрать число посимвольно слева направо и склеить результаты, строки — самый простой и очевидный путь.

???+ "Best Practices:"
    ```cpp
    int square_digits(int n) {
      int a = 1;
      int m = 0;
      while (n > 0) {
        int d = n % 10;
        m += a * d * d;
        a *= d <= 3 ? 10 : 100;
        n /= 10;
      }
      return m;
    }
    ```
    Этот подход считается лучшим для высоконагруженных систем, так как он работает без выделения памяти под строки. Он идет с конца числа через `% 10`, но сдвигает квадраты влево с помощью множителя `a`, подстраивая его размер (`10` или `100`) под длину получившегося квадрата.

## Задача 41: "Highest and Lowest"

In this assignment you are given a string of space separated numbers, and have to return the highest and lowest number.

???+ "На русском:" 
    Напишите функцию, которая принимает строку из чисел, разделенных пробелами, и возвращает самое большое и самое маленькое число через пробел. Максимум должен идти первым.

```cpp
// Пример использования:
highAndLow("1 2 3 4 5");  // => returns "5 1"
highAndLow("1 2 -3 4 5"); // => returns "5 -3"
highAndLow("1 9 3 4 -5"); // => returns "9 -5"
```

???+ "Решение:"
    ```cpp
    #include <string>
    #include <sstream>
    #include <algorithm> // Для функций std::max и std::min

    std::string highAndLow(const std::string& numbers){
        std::stringstream ss(numbers);
        int num;
        
        // Считываем самое первое число для инициализации минимума и максимума
        ss >> num;
        int max = num;
        int min = num;
        
        // Читаем все остальные числа из потока по очереди
        while (ss >> num) {
            max = std::max(max, num);
            min = std::min(min, num);
        }
        
        // Склеиваем результат в строку: максимум, пробел, минимум
        return std::to_string(max) + " " + std::to_string(min);
    }
    ```

???+ "На заметку:"
    <small>**`std::stringstream`** — превращает строку в поток данных. Позволяет читать слова или числа по очереди, автоматически пропуская пробелы.  
    **`ss >> num`** — считывает следующее число из потока. Возвращает `false`, когда числа в строке закончились, что идеально подходит для условия цикла `while`.  
    **`std::max / std::min`** — встроенные функции, которые выбирают наибольшее или наименьшее из двух переданных чисел.  
    **`std::to_string`** — переводит итоговые числа обратно в текстовый формат `std::string` перед склейкой.</small>

<br>
> <big>Инсайт дня: Потоковое чтение против ручного парсинга</big>

Использование `stringstream` избавляет от необходимости вручную искать пробелы, резать строку на подстроки и проверять знаки минус у отрицательных чисел. Поток сам понимает, где кончается одно число и начинается другое.

**Почему это важно:**  
Инициализация `min` и `max` первым прочитанным числом защищает от ошибок. Если вместо этого использовать `0`, код сработает неверно на строке, состоящей только из отрицательных чисел (например, `"-5 -10 -3"` ошибочно выдаст максимум `0`).

> **Вывод:** Для разбора строк с неизвестным количеством чисел, разделенных пробелами или табами, `stringstream` — самый надежный и лаконичный инструмент в C++.

???+ "Best Practices:"
    ```cpp
    #include <string>
    #include <sstream>
    #include <climits>

    std::string highAndLow(const std::string& numbers) {
        std::stringstream ss(numbers);
        int i, min = INT_MAX, max = INT_MIN;
        while (ss >> i) {
            if (i < min) min = i;
            if (i > max) max = i;
        }
        return std::to_string(max) + " " + std::to_string(min);
    }
    ```
    Этот подход считается лучшим, так как переменные здесь инициализируются экстремальными значениями (`INT_MIN` и `INT_MAX`) из библиотеки `<climits>`. Любое реальное число из строки гарантированно окажется больше `INT_MIN` и меньше `INT_MAX` при первой же проверке внутри цикла.

## Задача 42: "Find the odd int"

Given an array of integers, find the one that appears an odd number of times.

There will always be only one integer that appears an odd number of times.

???+ "На русском:" 
    Дан массив целых чисел. Найдите то число, которое встречается нечетное количество раз. В массиве всегда будет только одно такое число.

```cpp
// Пример использования:
findOdd({7});                                   // => returns 7 (встречается 1 раз)
findOdd({0, 1, 0, 1, 0});                       // => returns 0 (встречается 3 раза)
findOdd({1, 2, 2, 3, 3, 3, 4, 3, 3, 3, 2, 2, 1}); // => returns 4 (встречается 1 раз)
```

???+ "Решение:"
    ```cpp
    #include <vector>

    int findOdd(const std::vector<int>& numbers){
        int a = 0;
        
        // Перебираем все элементы массива и применяем XOR
        for (int i = 0; i < numbers.size(); i++) {
            a ^= numbers[i];
        }
        
        return a;
    }
    ```

???+ "На заметку:"
    <small>**`^=`** — оператор побитового исключающего ИЛИ (XOR) с присваиванием. Строка `a ^= numbers[i];` эквивалентна `a = a ^ numbers[i];`.  
    **`A ^ A = 0`** — фундаментальное свойство XOR. Любое число, примененное само к себе через эту операцию, уничтожает себя и дает ноль.  
    **`A ^ 0 = A`** — любое число при операции с нулем остается неизменным.  
    **Порядок операций** — для XOR порядок не имеет значения (`A ^ B ^ A` превратится в `0 ^ B`, что равно `B`). Это позволяет «гасить» парные числа, в каком бы месте массива они ни находились.</small>

<br>
> <big>Инсайт дня: Низкоуровневая магия железа против лишней памяти</big>

Использование побитовой операции `XOR` позволяет решить задачу за один единственный проход по массиву, не используя массивы-счетчики, сортировку или сложные структуры данных для подсчета частоты.

**Почему это важно:**  
Все числа, которые встречаются четное количество раз, гарантированно уничтожат друг друга в процессе вычислений (превратятся в 0). В переменной-аккумуляторе останется только то единственное число, у которого не оказалось пары. Это дает максимальную скорость работы алгоритма (O(N) по времени) и нулевые затраты по оперативной памяти (O(1) по памяти).

> **Вывод:** Для поиска одиночных элементов среди парных дубликатов побитовый XOR — самый быстрый, эффективный и элегантный инструмент в C++.

???+ "Best Practices:"
    ```cpp
    #include <vector>

    int findOdd(const std::vector<int>& numbers) {
        int a = 0;
        for (auto const& num : numbers) {
            a ^= num;
        }
        return a;
    }
    ```
    Этот подход использует современный цикл **`range-based for`** (for-each). Он избавляет код от ручной работы с индексами `[i]` и проверок `numbers.size()`. Конструкция `auto const& num` автоматически и безопасно берет каждый элемент массива по очереди, делая код чище и защищая от случайного выхода за границы памяти.

## Задача 43: "Descending Order"

Your task is to make a function that can take any non-negative integer as an argument and return it with its digits in descending order. Essentially, rearrange the digits to create the highest possible number.

???+ "На русском:" 
    Напишите функцию, которая принимает любое неотрицательное целое число и возвращает его же, но так, чтобы все цифры были отсортированы по убыванию (от большей к меньшей). Фактически, нужно составить максимально возможное число из этих цифр.

```cpp
// Пример использования:
descendingOrder(42145);  // => returns 54421
descendingOrder(145263); // => returns 654321
descendingOrder(123456); // => returns 654321
```

???+ "Решение:"
    ```cpp
    #include <cinttypes>
    #include <string>
    #include <utility> // Для функции std::swap

    uint64_t descendingOrder(uint64_t a)
    {
        std::string res = std::to_string(a);
        
        // Сортировка пузырьком (Bubble Sort) по убыванию
        for (size_t i = 0; i < res.size(); i++) {
            for (size_t j = i + 1; j < res.size(); j++) {
                if (res[i] < res[j]) {
                    std::swap(res[i], res[j]);
                }
            }
        }
        
        return std::stoull(res);
    }
    ```

???+ "На заметку:"
    <small>**`uint64_t`** — строго 64-битное целое положительное число. Используется, когда нужно гарантировать одинаковый огромный размер переменной на любых процессорах.  
    **`std::to_string`** — превращает число в строку `std::string`, что позволяет работать с отдельными цифрами как с символами.  
    **`res[i] < res[j]`** — проверка порядка. Если левая цифра меньше правой, значит, они стоят не по убыванию и их нужно поменять местами.  
    **`std::swap`** — встроенная функция, которая эффективно меняет содержимое двух ячеек памяти местами.  
    **`std::stoull`** — переводит строку обратно в 64-битное беззнаковое число (`unsigned long long`), предотвращая переполнение памяти.</small>

<br>
> <big>Инсайт дня: Строковый парсинг против математических разрядов</big>

Перевод числа в строковый формат перед сортировкой избавляет от необходимости вручную разбирать число на разряды через деление на 10, сохранять их в промежуточные массивы, а затем собирать число обратно через умножение.

**Почему это важно:**  
При работе с огромными 64-битными числами (до 18 квинтиллионов) ручная математическая сборка перевернутого числа может легко привести к ошибкам переполнения типов данных на промежуточных этапах. Строка выступает безопасным и наглядным буфером, где каждая цифра изолирована в своей ячейке памяти.

> **Вывод:** Когда задача требует перегруппировать, отсортировать или переставить цифры внутри числа, самый безопасный и читаемый путь в C++ — временно превратить число в `std::string`.

???+ "Best Practices:"
    ```cpp
    #include <cinttypes>
    #include <string>
    #include <algorithm>

    uint64_t descendingOrder(uint64_t a) {
        std::string s = std::to_string(a);
        
        // Сортировка с использованием обратных итераторов (по убыванию)
        std::sort(s.rbegin(), s.rend());
        
        return std::stoull(s);
    }
    ```
    Этот подход считается ультимативным лучшим решением, так как вместо ручных вложенных циклов использует встроенную эффективную функцию **`std::sort`**. Обратные итераторы **`rbegin()`** и **`rend()`** заставляют алгоритм сортировать контейнер «задом наперед» (от большего к меньшему), избавляя от необходимости подключать библиотеку `<functional>` для использования флага `std::greater`.

## Задача 44: "Stop gninnipS My sdroW!"

Your task is to make a function that takes in a string of one or more words, and returns the same string, but with all words that have five or more letters reversed (just like the name of this kata). Strings passed in will consist of only letters and spaces. Spaces will be included only when more than one word is present.

???+ "На русском:" 
    Напишите функцию, которая принимает строку, состоящую из одного или нескольких слов, и возвращает ту же строку, но с перевернутыми словами, длина которых составляет пять или более букв. Входные строки содержат только буквы и пробелы. Пробелы добавляются только тогда, когда в строке присутствует более одного слова.

```cpp
// Пример использования:
spinWords("Hey fellow warriors");  // => returns "Hey wollef sroirraw"
spinWords("This is a test");        // => returns "This is a test"
spinWords("This is another test"); // => returns "This is rehtona test"
```

???+ "Решение:"
    ```cpp
    #include <string>
    #include <algorithm> // Для функции std::reverse

    std::string spinWords(const std::string &str)
    {
        std::string result = "";
        std::string s = "";
      
        for (size_t i = 0; i < str.size(); i++) {
            if (str[i] != ' ') {
                s += str[i];
            } else {
                // Если встретили пробел, проверяем длину накопленного слова
                if (s.size() >= 5) {
                    std::reverse(s.begin(), s.end());
                }
                result += s + " ";
                s = ""; // Очищаем буфер для следующего слова
            }
        }
      
        // Обработка последнего слова после выхода из цикла (так как в конце строки нет пробела)
        if (s.size() >= 5) {
            std::reverse(s.begin(), s.end());
        }
        result += s;

        return result;
    }
    ```

???+ "На заметку:"
    <small>**`std::reverse`** — стандартная функция, переворачивающая элементы в заданном диапазоне (изменяет саму строку `s` на месте).  
    **`s.size() >= 5`** — ключевое условие задачи. Проверяет, состоит ли текущее слово из пяти или более символов.  
    **`result += s + " "`** — конкатенация строк. Добавляет обработанное слово и возвращает пробел на место в результирующую строку.  
    **`s = ""`** — операция сброса строкового буфера. Необходима, чтобы буквы нового слова не приклеивались к концу предыдущего.  
    **`result += s`** — финальное добавление хвоста строки вне цикла. Защищает алгоритм от потери последнего слова, за которым не следовал пробел.</small>

<br>
> <big>Инсайт дня: Логика граничных условий в посимвольном парсинге</big>

При ручном разборе строки посимвольно (через цикл `for`) триггером для окончания обработки слова обычно выступает разделитель — в данном случае пробел. Однако реальные текстовые строки практически никогда не заканчиваются пробелом, они заканчиваются концом самой строки (`\0`).

**Почему это важно:**  
Если забыть обработать накопленный буфер `s` сразу после завершения цикла, программа совершит критическую логическую ошибку — «потеряет» последнее слово строки. Ввод `"Hey warriors"` вернет только `"Hey "`, так как слово `"warriors"` останется заблокированным внутри переменной `s`.

> **Вывод:** При написании кастомных парсеров, завязанных на символы-разделители, всегда проверяйте состояние буферов после выхода из основного цикла. Последний элемент коллекции всегда требует индивидуальной ручной доработки.

???+ "Best Practices:"
    ```cpp
    #include <string>
    #include <sstream>
    #include <algorithm>

    std::string spinWords(const std::string &str) {
        std::stringstream ss(str);
        std::string word;
        std::string result = "";
        
        while (ss >> word) {
            if (word.length() >= 5) {
                std::reverse(word.begin(), word.end());
            }
            if (!result.empty()) {
                result += " "; // Добавляем пробел перед каждым словом, кроме первого
            }
            result += word;
        }
        
        return result;
    }
    ```
    Данный подход является эталонным для C++. Использование **`std::stringstream`** элегантно решает проблему «последнего слова», так как строковый поток самостоятельно извлекает слова по пробелам и корректно завершает цикл `while`, когда поток пустеет. Проверка `!result.empty()` избавляет от появления лишних пробелов в начале или конце итоговой строки.
